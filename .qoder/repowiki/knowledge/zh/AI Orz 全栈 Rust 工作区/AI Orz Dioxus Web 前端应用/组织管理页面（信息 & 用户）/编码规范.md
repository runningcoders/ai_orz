- 页面组件通过 `use_signal` 维护表单字段与 UI 状态（loading、saving、modal 显隐等），并在 `use_effect` 中 `spawn` 异步任务调用 API 后更新信号。
- 异步 API 调用统一采用 `match result { Ok(_) => toast.success(...), Err(e) => toast.error(&e) }` 的错误处理模式，并通过 `use_toast()` 反馈结果。
- 可选字段在构造请求 DTO 时使用 `if field.is_empty() { None } else { Some(field) }` 的模式将空字符串转换为 `None`，再交给后端处理。
- 用户角色通过本地辅助函数 `role_badge` / `role_text` 将数字枚举映射为 DaisyUI badge 类名与中文文案，避免在模板中散落硬编码。
- 所有页面组件外层统一包裹 `AppLayout`，并以 `card bg-base-100 shadow-md` 的卡片容器组织内容区域。
