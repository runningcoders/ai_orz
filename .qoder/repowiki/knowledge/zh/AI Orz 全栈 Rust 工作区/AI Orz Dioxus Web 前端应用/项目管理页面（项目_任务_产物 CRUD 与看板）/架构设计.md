模块以 `mod.rs` 聚合 7 个 Dioxus 组件文件，按资源维度划分：`projects.rs`/`project_detail.rs` 管理项目列表与详情；`tasks.rs`/`task_detail.rs`/`task_edit_modal.rs` 实现任务列表（支持列表/看板双视图）、详情页（含概览、进度与状态、关系图、产物四个 Tab）及内联编辑弹窗；`artifacts.rs`/`artifact_detail.rs` 负责产物列表、创建、删除与内容查看/编辑。每个组件都是独立的 `#[component]`，通过 `use_signal` 维护本地 UI 状态，使用 `use_effect` + `spawn(async move ...)` 发起异步 API 调用（来自 `crate::api::project`），并通过 `common::api` 中的请求/响应 DTO 与后端通信。UI 统一包裹在 `AppLayout` 中，复用 `components::modal`、`components::state::{Loading, EmptyState}`、`store::toast::use_toast` 以及 `layouts/app_layout`。路由跳转通过 `dioxus_router::Link` 和 `use_navigator` 完成，导航目标引用 `crate::pages::Route`。依赖方向单向：页面组件 → 共享 `api`/`components`/`utils`/`common`，不反向依赖其他页面。
