- 新增事件类型遵循「事件结构体 + 对应 StatTable 实现」成对放在独立文件（如 model_call.rs 同时包含 ModelCallEvent 与 ModelCallStatTable），并通过 `mod.rs` 统一 re-export。
- 事件结构体使用 `#[derive(StatsEvent)]` 宏标注，并以 `#[tag]` / `#[metric]` 属性区分维度标签与数值指标，由 derive 自动生成 `StatEvent` 实现。
- 专用统计表通过实现 `is_dedicated_table() = true` 声明拥有独立列，而通用表保持默认返回 false 以使用 JSON 列存储 tags/metrics。
- 写路径统一经 `Stats::record` 进入 `ErasedBuffer` 缓冲，达到 `batch_size` 后批量 flush，避免每次记录都落库。
- 查询过滤通过 `StatFilter::Equals` / `StatFilter::Range` 枚举组合，由 `append_filters` 统一拼接 SQL 并收集 `StatParam` 参数，禁止直接拼接用户输入。
- 并发安全通过「细粒度 Mutex + 固定锁序」实现：flush 时先持 tables 锁取走 buffer，再持 conn 锁执行批量插入，避免与 record 路径死锁。
