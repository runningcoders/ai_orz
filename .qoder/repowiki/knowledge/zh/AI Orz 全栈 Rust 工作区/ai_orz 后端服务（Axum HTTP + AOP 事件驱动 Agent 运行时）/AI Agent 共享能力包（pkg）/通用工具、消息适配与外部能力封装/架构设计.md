本模块由四个并列子包组成，均作为基础设施层被上层 producer/业务模块依赖：
- `pkg/utils/graph`：定义 `Graph`/`Node`/`Line` 抽象（types.rs）并通过 `GraphRenderer` trait 解耦输出格式，当前仅实现 Mermaid 渲染器（renderer.rs），遵循“数据模型与渲染策略分离”的设计。
- `pkg/adapter`：核心为两个注册中心——`AdapterRegistry`（按 `ChannelType` 以 `Arc<dyn Any>` 存储具体 DAL 实例，供 producer downcast 取用）和 `MessageAdapterRegistry`（管理实现 `MessageInboundAdapter` trait 的渠道 DAL，统一 `start_all`/`stop_all` 生命周期）。两者都通过 `once_cell::sync::Lazy` 暴露全局单例 `registry()`，并依赖 `common::enums::ChannelType` 做路由键；`AdaptedMessage` 是 DAL→producer 的 owned 转换结果，回调通过 `MessageAdapterCallback` trait 注入。
- `pkg/external`、`pkg/monitoring`：当前为预留占位模块，分别用于外部 API 封装与运行时监控扩展。
依赖方向严格单向：adapter/message 不依赖任何 DAO/DAL 类型，仅通过 trait 与 `common` 枚举耦合，保证新增渠道无需修改中台代码。
