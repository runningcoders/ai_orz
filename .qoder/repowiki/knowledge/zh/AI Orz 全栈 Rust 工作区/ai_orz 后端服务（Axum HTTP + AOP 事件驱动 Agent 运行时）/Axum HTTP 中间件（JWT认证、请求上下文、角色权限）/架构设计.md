模块以 `mod.rs` 统一暴露三个独立中间件：`jwt_auth_middleware`（`jwt_auth.rs`）、`request_context_middleware`（`request_context.rs`）、`require_role_middleware`（`require_role.rs`）。三者按固定顺序组合使用——`jwt_auth_middleware` 作为最外层先解析 Cookie/Bearer 中的 JWT，验证后将 user_id、username、organization_id、role、caller_type 写入请求头；紧随其后的 `request_context_middleware` 从这些请求头构造 `RequestContext` 并通过 `axum::Extensions` 注入到请求扩展中，同时负责 LogId 的生成与写回响应头；最内层的 `require_role_middleware` 从 `RequestContext` 取出用户角色，调用 `UserRole::has_permission` 基于并查集继承关系判断是否满足最低角色要求。依赖方向单向向外：本模块仅依赖 `crate::pkg::{jwt, RequestContext}` 与 `common::*`，不反向被业务 handler 引用，仅通过 Axum 中间件链装配。
