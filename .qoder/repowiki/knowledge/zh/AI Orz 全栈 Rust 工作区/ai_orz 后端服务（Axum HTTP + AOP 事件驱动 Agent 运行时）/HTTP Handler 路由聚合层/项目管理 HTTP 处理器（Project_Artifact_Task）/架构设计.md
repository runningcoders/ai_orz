模块以 `mod.rs` 为入口，将功能划分为三个子域：`projects`（项目 CRUD）、`artifact`（工件上传/下载/查询）、`task`（任务创建/状态流转/进度更新）。每个子域采用「按 HTTP 方法拆文件」的扁平结构（如 `create_project.rs`、`get_project.rs`），并在各自的 `mod.rs` 中集中 `pub use` 暴露 `*_handler` 函数；每个 handler 文件对应一个独立的 HTTP 端点，职责单一。所有 handler 均使用 `ai_orz_macros::generate_http_handler` 和 `register_handler_tool` 宏自动完成路由绑定与 OpenAPI/工具元数据生成，并通过 `RequestContext` 获取当前用户上下文。业务逻辑全部委托给 `crate::service::domain::project` 下的领域服务（`project_manage()`、`artifact_manage()`、`task_manage()`），handler 仅做参数校验、错误转换与响应组装；各子域还维护本地 `response.rs` 将领域模型转换为 `common::api::*` 响应 DTO。`artifact/mime_util.rs` 提供 MIME 类型推断等共享工具，被工件相关 handler 复用。
