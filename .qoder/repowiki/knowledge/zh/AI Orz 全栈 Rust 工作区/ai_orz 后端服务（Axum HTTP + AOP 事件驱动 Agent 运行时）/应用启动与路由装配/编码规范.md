- 全局状态通过 `std::sync::OnceLock<Arc<T>>` 持有，并提供 `get()` 与 `try_get()` 两种访问方式，后者用于测试或可选初始化场景避免 panic。
- 日志统一通过 `log_info!`/`log_warn!`/`log_error!`/`log_debug!` 宏输出，支持无上下文（直接传消息）与带 `RequestContext` 上下文（第一个参数为 ctx，第二个为 operation 字面量）两种调用形式。
- 路由按权限分层：public_routes 与 protected_routes 分别用 `nest("/api/v1", ...)` 挂载，受保护路由统一在外层添加 `jwt_auth_middleware`，内层再添加 `request_context_middleware`，遵循外层先执行的洋葱模型。
- 每个业务域（hr/finance/system/organization/project/task/user）在 router.rs 中拆分为独立的 `*_routes()` 函数，集中注册该域的所有 RESTful 端点，保持路由表可维护性。
- 配置默认值通过 `include_str!("../common/config/ai_orz.toml")` 编译时嵌入，运行时若配置文件不存在则自动写出，确保零配置即可运行。
