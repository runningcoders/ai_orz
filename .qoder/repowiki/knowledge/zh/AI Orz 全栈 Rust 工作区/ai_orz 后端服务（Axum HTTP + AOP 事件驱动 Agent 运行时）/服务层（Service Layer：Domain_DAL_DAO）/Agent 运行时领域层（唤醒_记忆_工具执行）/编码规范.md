- 所有对外能力通过 `#[async_trait]` trait 暴露，由 `RuntimeDomainImpl` 统一实现并以 `Arc<dyn Trait>` 形式聚合，避免直接持有具体类型。
- DAL 访问统一通过 `use crate::service::dal::*::dal()` 局部引入后调用，保持对全局 DAL 工厂的隐式依赖。
- Agent 生命周期状态变更采用 RAII 模式：先 `set_busy` / `set_resting`，再创建 `BusyGuard`，利用 `Drop` 保证 `set_idle` 在任意返回路径执行。
- 思考循环通过 `ThinkingScene` 枚举 + `is_tool_allowed` 按 tag 过滤工具/技能，Awaken/Settle/Summary 三种场景分别限定可用工具集合。
- 工具调用失败时对 MCP 与 Builtin/Http 走不同错误映射路径，Builtin/Http 一律脱敏为通用消息，MCP 则根据关键词归一化为 timeout/server disabled 等可读错误。
- 查询类入口统一在 `tool_call_query` 中合并 `RequestContext` 作用域并校验冲突与上限，禁止无 scope 的跨租户查询。
