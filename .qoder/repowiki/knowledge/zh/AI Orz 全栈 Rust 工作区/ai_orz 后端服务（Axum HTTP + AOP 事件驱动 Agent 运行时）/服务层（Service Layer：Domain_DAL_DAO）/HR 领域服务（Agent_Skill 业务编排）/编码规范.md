- 所有领域方法签名统一接收 `ctx: RequestContext` 作为首参，并通过 `enrich_ctx!` 在需要时追加 Agent 上下文以便下游复用。
- 对外暴露的领域能力通过 `trait`（`HrDomain`/`AgentManage`/`SkillManage`）定义，具体逻辑由 `HrDomainImpl` 实现，便于测试时通过 `new()` 注入 mock DAL。
- 对可重复执行的操作（install/uninstall_tool_pack、install/uninstall_skill_pack、reinstall_skill_pack）采用幂等设计：先检查是否已安装再跳过，并记录相应日志。
- DAL 调用前进行领域级前置校验（如 Local Agent 必须指定 model_provider_id、状态流转合法性、作者权限、乐观锁 `updated_at` 匹配），失败统一用 `bail_err!` 返回结构化错误。
- Agent 状态机集中在 `transition_status` 中用 match 枚举合法转换路径，非法转换直接拒绝；同状态跳转视为幂等。
- Skill 文件操作统一经过 `validate_skill_import_target_path` 校验目标路径，禁止绝对路径、反斜杠、目录结尾、覆盖 `skill.md` 等危险路径片段。
