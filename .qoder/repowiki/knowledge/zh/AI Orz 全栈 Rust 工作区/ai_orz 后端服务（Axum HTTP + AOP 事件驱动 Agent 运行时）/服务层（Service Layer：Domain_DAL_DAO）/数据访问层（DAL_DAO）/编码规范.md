- 每个 DAO 子模块在 `mod.rs` 中声明 `Send + Sync` 的 async trait 与查询参数结构体，再通过 `sqlite.rs`/`vector.rs`/`stats_duckdb.rs` 提供多后端实现，并由 `mod.rs` 统一 `init()` 注册到 `OnceLock` 单例。
- DAL 模块通过 `static XXX_DAL: OnceLock<Arc<dyn XxxDal>>` 暴露全局单例，并提供 `dal()` 获取器与 `init()` 装配器，构造时注入多个下游 DAO trait 对象。
- 搜索统一采用 `XxxQuery`（过滤条件）+ `XxxSearch`（keyword + query_vector + top_k + filters）双结构，DAL 层根据是否提供 keyword/query_vector 决定走 FTS5、向量或混合搜索。
- 对可选能力（如 Embedding Provider、向量索引写入、stats 查询）采用“失败 warn 降级”策略：记录日志后跳过，不阻断主流程。
- DTO 转换集中在 DAL 层：DAO 返回持久化 PO（`AgentPo`/`MessagePo`），DAL 通过 `from_po` 转换为业务对象并注入 runtime_state、search_match、stats 等附加信息。
- 统计类 DAO 使用泛型关联类型（如 `AgentStatsDao::AwakeEvent`）配合 `StatEvent`/`StatAggregation` 框架，通过 `StatsFetchOptions` 控制 call_summary/token_summary/time_series 的按需加载。
