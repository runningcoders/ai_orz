模块以 `mod.rs` 为入口，通过 `OnceLock<Arc<dyn OrganizationDomain>>` 暴露全局单例 `domain()`/`init()`，实现依赖注入；`OrganizationDomainImpl` 聚合 `organization::OrganizationDal` 与 `user_dal::UserDal` 两个 DAL 抽象，对外暴露 `OrganizationManage` 与 `UserManage` 两个子 trait，分别由 `org.rs` 与 `user.rs` 实现。依赖方向单向向下：Domain → DAL（`crate::service::dal`），不反向依赖上层 handler；ID 生成（`generate_org_id`/`generate_user_id`）在 Domain 层完成，业务编排（如 `create_org_and_owner` 同时建组织与超级管理员用户、`verify_password` 校验用户名/密码/状态/组织归属）集中在 Domain 层，DAL 仅做数据透传。
