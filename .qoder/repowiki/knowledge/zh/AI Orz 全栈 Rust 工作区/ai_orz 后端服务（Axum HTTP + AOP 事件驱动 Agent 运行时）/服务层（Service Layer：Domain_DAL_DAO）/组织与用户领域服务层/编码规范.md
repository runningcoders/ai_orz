- 所有领域方法签名统一接收 `RequestContext` 作为首参，并通过 `common::error::Result` 返回结果。
- DAL 调用采用薄包装模式：大多数方法直接透传参数到对应 DAL，仅在需要组合多个 DAL 或添加业务规则时（如 `create_org_and_owner`、`verify_password`、`count_by_organization_id`）进行编排。
- 通过 `OrganizationDomain` trait 聚合 `organization_manage()` / `user_manage()` 两个子能力，并以 `OnceLock` + `Arc` 暴露全局单例供上层消费。
- ID 生成函数集中定义在 `org.rs`，使用固定字符集与长度常量（组织 12 位、用户 16 位）配合 `rand::thread_rng` 随机生成。
