模块以 `mod.rs` 为入口，通过 `FinanceDomain` trait 聚合六个子领域（ModelProviderManage、MessageChannelManage、AttachmentManage、McpServerManage、McpToolManage、ToolProviderManage），并由 `FinanceDomainImpl` 持有各 DAL（ModelProviderDal、MessageChannelDal、McpServerDal、McpToolDal、ToolDal、BrainDal、AttachmentDal）的 `Arc<dyn ...>` 依赖注入实现；全局通过 `OnceLock<Arc<dyn FinanceDomain>>` 暴露单例 `domain()`，并提供 `init()` / `new()` 两种初始化方式（生产用全局 DAL 单例，测试用独立实例保证隔离）。每个子领域拆分为单独文件（`model_provider.rs`、`message_channel.rs`、`attachment.rs`、`mcp_server.rs`、`tool_provider.rs`、`mcp_tool.rs`），在各自文件中对 `FinanceDomainImpl` 实现对应 Manage trait，DAL 调用被薄包装在 Domain 层之上，仅在此层进行业务规则校验（如 MCP 配置脱敏合并、Embedding Provider 切换原子性、Agent 绑定 internal 工具禁止、Attachment 文本大小/MIME/路径穿越校验等）。依赖方向单向向下：Domain → DAL → DAO/DB，不反向依赖上层 API。
