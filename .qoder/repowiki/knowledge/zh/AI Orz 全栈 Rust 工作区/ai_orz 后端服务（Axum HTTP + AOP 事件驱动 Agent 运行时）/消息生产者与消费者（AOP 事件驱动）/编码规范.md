- 每个 Consumer/Producer 实现 `async_trait` 的 `Consumer`/`Producer` trait，并提供 `new()` + `Default` 构造，通过 `mod.rs` 的 `init()` 集中注册到 `aop::registry()`。
- 事件负载统一先反序列化为强类型结构体（如 `MessageCreatedEvent`、`CronTriggerEvent`、`TaskStatusChangedEvent`），再根据字段进行 match 分支处理。
- 消费者中涉及跨进程/线程调用的领域操作一律通过 `RequestContext::new_system()` 或 `RequestContext::builder()` 重建上下文，确保追踪链与租户信息完整。
- 对可能阻塞的 Agent 资源采用 `AgentRuntimeStateManager::global().try_set_busy()/set_idle()` 显式占用-释放模式，并在失败路径显式清理以避免死锁。
- 生产者通过 `RwLock<Option<Arc<Registry>>>` 延迟持有 Registry 引用，在 `register()` 阶段写入、`poll()` 阶段读取，避免循环依赖。
- 消费者通过 `consume_mode()` 声明 `ConsumeMode::Sync` 或 `ConsumeMode::Async`，并由框架调度器决定执行方式，业务代码无需感知调度细节。
