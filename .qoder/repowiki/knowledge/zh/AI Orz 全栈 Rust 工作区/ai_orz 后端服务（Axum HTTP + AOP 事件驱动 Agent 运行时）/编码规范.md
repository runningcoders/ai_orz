- HTTP 路由在 `router.rs` 中集中按域（hr/finance/system/organization/project/user/a2a）用 `Router::nest` 组合，handler 仅负责参数解析与调用 service，不包含业务逻辑。
- 中间件采用 Axum layer 洋葱模型：外层 `jwt_auth_middleware` 验签，内层 `request_context_middleware` 从请求头构造 RequestContext，保证下游可访问用户与 log_id。
- 日志统一使用根模块导出的 `log_info!` / `log_warn!` / `log_error!` / `log_debug!` 宏，带 ctx 时自动创建 tracing span 并注入字段。
- Domain→DAL→DAO 三层职责清晰：Domain 表达业务规则，DAL 封装聚合查询，DAO 面向具体 SQLite/DuckDB 表结构，测试按同文件 `*_test.rs` 组织。
- AOP 事件通过 `producer` 发布、`consumer` 订阅，新增事件需同时定义 `models::events` 中的事件类型并在对应 producer/consumer 中注册。
- 跨模块共享能力（日志、存储、JWT、工具注册、AOP 核心）统一放在 `pkg` 并通过 `init_all` 一次性初始化，避免各子模块重复装配。
