模块位于 frontend/src/components/markdown.rs，是前端共享 UI 层的一个独立组件文件，不依赖业务模块。
- 解析层：`render_markdown` 使用 pulldown-cmark 启用 TABLES、STRIKETHROUGH、TASKLISTS 扩展，并将所有原始 HTML 事件降级为 Text 文本，再通过 `dangerous_inner_html` 注入 DOM，保证 XSS 安全。
- 组件层：`MarkdownRenderer` 通过 `use_memo` 缓存 HTML 避免重复解析；当内容包含 `language-mermaid` 时，挂载后延迟 30ms 扫描并调用全局函数替换代码块为 SVG。
- 图表层：`MermaidDiagram` 直接接收裸 Mermaid 字符串，通过 `spawn` 异步调用 `window.__renderMermaidCode` 渲染。
- JS 互操作层：`call_window_fn` 通过 `js_sys::Reflect` 读取 window 上的全局函数名（`__renderMermaid` / `__renderMermaidCode`），不存在或类型不符时静默跳过，使 mermaid.js 成为可选依赖；容器 ID 由进程级 `AtomicUsize` 自增生成，确保同页多实例隔离。
- 样式约定：输出元素统一使用 `.markdown-body` 类，复用 `input.css` 中基于 DaisyUI 主题变量的 Markdown 样式，并提供 `markdown-compact` 变体用于卡片/气泡等紧凑场景。
