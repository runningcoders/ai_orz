- 通过 `use_memo` 缓存 Markdown → HTML 的结果，避免聊天列表等高频重渲染场景重复解析。
- 所有原始 HTML 事件在解析阶段被映射为 Text 再注入 DOM，禁止透传任意 HTML，以保障 `dangerous_inner_html` 注入安全。
- 对可选的外部 JS 能力统一通过 `call_window_fn` 反射式调用，函数缺失或类型不符时静默跳过而非抛错。
- DOM 容器 ID 由进程级 `AtomicUsize` 计数器生成（带前缀），确保同页多个组件实例互不干扰。
- Mermaid 渲染采用延迟策略：先输出带 `language-mermaid` class 的代码块，挂载后通过 `gloo_timers::sleep(30ms)` 等待 DOM 就绪再触发渲染。
