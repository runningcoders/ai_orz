- 每个页面导出一个 `pub fn Xxx() -> Element` 的 Dioxus 组件，并在 `mod.rs` 中 `pub mod` 暴露。
- 列表页统一采用“三场景切换”模式：无关键词+无过滤走 list_*，无关键词+有过滤走 query_*，有关键词走 search_*，并复用同一 `load_data` 函数。
- 搜索输入框使用 `search_request_id` 自增信号配合 `gloo_timers::future::TimeoutFuture::new(300)` 实现防抖，并在回调内比对 ID 丢弃过期请求结果，避免 race condition。
- 删除操作先弹出 `ConfirmDialog`，在 `on_confirm` 中 `spawn` 异步调用 delete_* API，成功则刷新列表。
- 表单字段统一用 `use_signal` 维护，Modal 关闭时在 `on_close` 中重置所有字段，防止状态污染。
- 错误处理统一通过 `use_toast().error(...)` 提示，成功路径调用 `toast.success(...)` 或静默刷新。
