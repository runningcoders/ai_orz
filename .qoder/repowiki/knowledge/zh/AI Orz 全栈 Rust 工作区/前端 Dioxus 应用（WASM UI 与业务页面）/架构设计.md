以 `src/main.rs` 启动 Dioxus 应用，在根组件中通过 `use_context_provider` 注入 AuthState、Toast、Theme、移动端断点等跨页上下文，并挂载 `Router::<Route>` 与各业务域页面（finance/hr/message/organization/project/system/user）。所有页面统一通过 `src/api/` 下按领域拆分的 HTTP 客户端调用后端，错误经 `ApiError` 统一处理；UI 复用由 `components/`、`layouts/`、`hooks/`、`store/`、`utils/` 提供的共享基础设施支撑。构建阶段由 `build.rs` 将 common crate 中的配置编译进 `compiled_config.rs`，运行时由 `config.rs` 暴露给各模块；WASM 产物经 dioxus-cli 输出到 `pkg/`，Tailwind 样式编译至 `public/output.css` 并由 `index.html` 加载。前后端通过 common crate 共享 DTO/枚举/错误类型，确保页面侧请求与响应结构与后端一致。当前变更方向是将所有 Markdown 性质字段（详情页字段、聊天消息、记忆内容、执行计划/结果）统一通过可复用的 Markdown 渲染组件展示，并通过 vendor mermaid.js + JS interop 支持 Mermaid 图表。
