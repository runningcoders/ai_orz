模块以 `mod.rs` 为入口，将每个子系统拆分为独立文件（aop、backup、docs、health、logs、seed、tasks、triggers），每个文件导出一个顶层 `#[component]` 函数（如 `SystemHealth`、`SystemLogs`、`SystemTasks`、`SystemBackup`、`SystemAop` 等），统一由 `AppLayout` 包裹内容区域。所有页面通过 `crate::api::*` 下的后端 API 客户端发起异步请求，使用 `crate::store::toast::use_toast()` 进行成功/错误提示，并通过 `crate::components::{gauge, charts, modal, state}` 等共享 UI 组件渲染指标、图表与弹窗。轮询刷新采用两种模式：`use_effect + spawn + loop + sleep_ms`（health 10s、aop 5s）或 `use_future + gloo_timers::TimeoutFuture`（tasks 3s，组件卸载自动取消）。状态管理统一使用 Dioxus `Signal`，列表/筛选/分页等交互在组件内完成，无全局 store；wasm 环境下 `sleep_ms` 通过 `js_sys::Promise` + `web_sys::setTimeout` 实现定时。
