- 每个子系统页面以独立文件组织并在 `mod.rs` 中 `pub mod` 暴露，顶层导出 `SystemXxx` 组件函数。
- 页面统一通过 `AppLayout` 包裹内容区域，并使用 `use_toast()` 获取 toast 实例来展示成功/错误提示。
- 异步数据加载采用 `spawn(async move { ... })` 模式，调用 `crate::api::*` 后对 `Ok`/`Err` 分支分别设置信号并调用 `toast.success/error`。
- 需要周期性刷新的页面使用 `use_effect` + `spawn` + `loop` + 自定义 `sleep_ms` 实现轮询（health 10 秒、aop 5 秒），tasks 页面改用 `use_future` + `gloo_timers::TimeoutFuture` 以获得自动取消能力。
- 列表页通过 Dioxus `Signal` 维护表单字段、当前页码、展开状态等局部状态，筛选变化时重置页码并重新发起查询。
- 可复用 UI 通过共享组件实现：Gauge/AopGauge 展示指标、DonutChart/LineChart 展示统计、Modal 承载详情弹窗、Loading/EmptyState 处理空态与加载中。
