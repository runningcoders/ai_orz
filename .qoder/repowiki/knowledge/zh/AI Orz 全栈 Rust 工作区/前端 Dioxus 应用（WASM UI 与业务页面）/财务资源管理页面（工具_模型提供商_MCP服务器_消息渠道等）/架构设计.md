模块以 `mod.rs` 集中导出各子模块，每个 `.rs` 文件对应一个独立的 Dioxus 组件页面，遵循「列表页 + 详情页」成对组织（如 `tools.rs`/`tool_detail.rs`、`mcp_servers.rs`/`mcp_server_detail.rs`、`message_channels.rs`/`message_channel_detail.rs`、`model_providers.rs`/`model_provider_detail.rs`、`attachments.rs`/`attachment_detail.rs`），另含 `tool_call_entries.rs` 作为独立子页面。
- 视图层：所有页面通过 `AppLayout` 包裹，使用 DaisyUI 类名（card/table/badge/button）构建表格化列表；状态展示复用 `components::state::{Loading, EmptyState}`。
- 路由层：通过 `dioxus_router::Link` 跳转到 `crate::pages::Route::Finance*` 路由，详情页接收 `id: String` 参数。
- 数据层：调用 `crate::api::finance::*` 下的异步函数（list/create/update/delete/test/sync/debug 等），请求/响应类型来自 `common::api`，枚举来自 `common::enums`，实现前后端契约解耦。
- 交互层：使用 `use_signal` 管理本地状态，`spawn(async move { ... })` 发起副作用；错误统一通过 `store::toast::use_toast()` 弹出提示；删除等危险操作通过 `components::confirm_dialog::ConfirmDialog` 二次确认；新增/编辑通过 `components::modal::Modal` 弹窗完成。
- 依赖方向：本模块仅向上依赖 `api`、`components`、`layouts`、`store`、`utils`、`common`，不反向被业务逻辑引用，属于纯表现层。
