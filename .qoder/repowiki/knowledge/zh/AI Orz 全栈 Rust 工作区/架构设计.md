根目录作为 Cargo workspace 入口（members = [".", "frontend", "common", "ai-orz-macros"]），将四层架构的后端服务（ai_orz）、跨前后端共享的 DTO/配置库（common）、横切 HTTP handler 生成宏（ai-orz-macros）以及 Dioxus WASM 前端聚合在同一份依赖图中；backend 通过 path dependency 引用 common 与 ai-orz-macros，frontend 仅依赖 common，从而保证前后端类型契约一致且前端不反向依赖后端实现。数据库 schema 由 migrations 子模块按时间戳演进，SQLX 在编译期通过 .sqlx/ 缓存校验查询。CI（.github/workflows/rust.yml）按 lint → backend/frontend 并行 → coverage 的顺序编排，使用 sccache 共享编译产物并以 cargo-llvm-cov 输出覆盖率报告。开发/构建/生产流程统一收敛到 start.sh（dev/build/prod/backend/frontend），build.sh 仅作为其别名。
