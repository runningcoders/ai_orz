模块以 `proc-macro = true` 的 Rust 过程宏 crate 形式组织，入口 `src/lib.rs` 通过 `mod stats_event` / `mod log_fields` 将具体实现拆分为独立文件：
- `stats_event.rs`：实现 `#[derive(StatsEvent)]`，扫描 `#[timestamp]`/`#[tag]`/`#[metric]`/`#[event_type]` 注解并生成 `crate::pkg::stats::StatEvent` trait 实现。
- `log_fields.rs`：实现 `#[derive(LogFields)]`，扫描 `#[log_field]` 注解并生成 `crate::pkg::logging::LogFields` trait 实现，按字段类型（String/Option<String>/其他）选择 Display/Debug 输出。
- `lib.rs` 还暴露两个过程属性宏：`#[register_handler_tool]` 将函数包装为 `BuiltinToolFactory`，通过 `schemars` 生成 JSON Schema 并借助 `ctor::ctor` 在启动时自动注册到工具注册表；`#[generate_http_handler]` 通过 `glob` + `syn::parse_file` 跨文件扫描 Params 结构体的 `#[param(source="path|query|body")]` 注解，根据 path/query/body 组合分支生成对应的 axum handler（支持 path+query+body 混合、`serde(flatten)` query 字段、空结构体无 body 提取器等场景）。
依赖方向单向：宏 crate 仅依赖 `syn`/`quote`/`proc-macro2` 做 AST 操作，并通过 `glob` 读取宿主工程源码进行静态分析，不引入业务逻辑。
