- HTTP 接口统一使用 `#[generate_http_handler]` 宏包裹核心函数，并在 Params 结构体字段上标注 `#[param(source = "path|query|body")]`，由宏自动生成 Axum 提取器与 `ApiResponse` 包装。
- Handler 函数签名固定为 `(ctx: RequestContext, params: Params) -> Result<Output, AppError>`，返回值经宏自动封装为 `common::api::ApiResponse`。
- 路由按业务域拆分子目录（hr/finance/system/project/organization/a2a/user），每个 handler 单独文件，由 `src/router.rs` 集中 `nest`/`route` 装配。
- 服务层严格遵循 Domain → DAL → DAO 单向依赖，禁止 DAO 调 DAO、DAL 调 DAL、Domain 调 Domain。
- 跨进程/协程事件通过 `src/pkg/aop` 事件总线发布，`src/producer` 负责入站事件生产，`src/consumer` 负责消费，并由 `consumer::init` / `producer::init` 在启动时注册。
- 日志统一使用根 crate 暴露的 `log_info!` / `log_warn!` / `log_error!` / `log_debug!` 宏，带上下文模式自动创建 tracing span 并注入 `LogFields` 标记字段。
