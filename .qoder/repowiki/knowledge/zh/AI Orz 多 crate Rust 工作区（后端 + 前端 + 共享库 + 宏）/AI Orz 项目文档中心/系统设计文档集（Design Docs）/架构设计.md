- 异步事件总线：consumer_architecture.md、event_design.md、message_channel_design.md、message_interaction_design.md、request_context_design.md、logging_design.md、stats_module_design.md、stats_query_design.md 描述基于 pkg/aop 的 Producer/Consumer/Registry 抽象、两阶段初始化（service::init → producer::init → consumer::init → init_base_data → aop::init_all）、Sync/Async 消费模式与 ack/nack 语义。
- 领域模型：organization_design.md、project_design.md、project_management_design.md、task_design.md、skill_design.md、agent_loop_engine_design.md、agent_onboarding_design.md、external_agent_design.md、entity_list_query_search_design.md 定义各业务实体与查询策略。
- 适配层与工具生态：unified-idl-http-handler.md、handler-tool-registration-macro.md、tool_design.md、generic_builtin_tools_design.md、mcp_tool_design.md、builtins_http_tool_design.md 描述 ai-orz-macros 提供的 #[generate_http_handler] + #[derive(Params)] + #[param(source=...)] 统一 IDL 方案，一份 Params 同时生成 axum handler 与 LLM 工具 JSON Schema。
- 前端架构：frontend_architecture.md、ui_design_system.md、canvas_rendering_playbook.md 描述 Dioxus 0.7 + Tailwind CSS 4 + DaisyUI 5 的前端分层（api/hooks/store/components/layouts/pages），以及 Canvas HUD 渲染基础设施。
- 运维与测试：testing_guidelines.md、browser_e2e_test_design.md、seed-config-migration.md、sqlx_guide.md、vector_search_architecture.md、attachment_storage.md、common-error-type.md 覆盖测试策略、浏览器 E2E、数据迁移、数据库、向量检索、附件存储与统一错误类型。
