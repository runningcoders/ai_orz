模块以 `main.rs` 为 WASM 应用入口，通过 `launch(App)` 启动 Dioxus 组件树，在 `App` 中集中提供 `AuthState`（认证状态）、Toast 通知、主题控制与移动端断点信号等全局上下文，并挂载 `<Router::<Route>>` 与 `ToastContainer`。
- 配置层：`config.rs` 定义 `FrontendConfig`，优先级为 localStorage > 编译时嵌入的 `compiled_config.rs`（由 `build.rs` 生成），并提供 `load/save/reset_to_default/api_url` 等访问方法；`settings.rs` 页面暴露 API Base URL 与主题切换。
- 路由层：`pages/mod.rs` 使用 `#[derive(Routable)]` 枚举 `Route` 集中声明所有业务路由（reception/message/organization/hr/finance/project/system/user/workspace/settings），并通过 `use_effect` + `spawn` 异步初始化各子模块页面。
- 页面实现：`reception.rs` 承担系统初始化与登录流程，调用 `api::auth`、`api::organization`、`api::seed` 完成组织创建、模型配置与任务进度轮询；`workspace.rs` 实现三栏驾驶舱视图（Project/Agent/Task 关系图 + 底部对话 + SSE 实时消息），通过 `WorkspaceView` 状态机驱动按需数据加载；`settings.rs` 仅负责本地配置持久化与主题切换。
- 依赖方向：页面 → `api::*` / `store::*` / `components::*` / `hooks::*` / `layouts::*` / `utils::*`，不反向依赖其他页面，路由枚举是唯一的跨页面边界。
