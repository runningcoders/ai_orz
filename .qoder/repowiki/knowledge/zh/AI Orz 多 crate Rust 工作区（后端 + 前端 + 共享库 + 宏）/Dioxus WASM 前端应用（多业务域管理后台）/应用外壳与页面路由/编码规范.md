- 页面组件统一通过 `use_signal` 管理局部状态，并通过 `use_effect` + `spawn(async move { ... })` 发起异步副作用（API 调用、SSE 订阅、定时器）。
- 用户反馈统一通过 `use_toast()` 获取 toast 句柄后调用 `.success/.error/.info` 显示提示，避免直接操作 DOM。
- 路由通过 `#[derive(Routable)]` 的 `Route` 枚举集中声明，新增页面只需在枚举中添加 `#[route("/path")]` 变体并在 `mod.rs` 顶部 `use` 对应组件。
- 配置读取遵循 localStorage 优先、编译时默认值兜底的策略，写回时使用 `FrontendConfig::save()` 并以 `ai_orz_config` 作为 key 存储。
- 表单提交采用 `onsubmit` + `e.prevent_default()` 模式，配合独立的 `*_submitting` 信号控制按钮禁用与文案切换。
- 对 `web_sys::window()` 的访问一律使用 `if let Some(window) = web_sys::window()` 安全分支，避免在非 Window 环境 panic。
