- 页面按业务域划分在 `pages/<domain>/` 下，每个域包含 `mod.rs` 导出路由与子页面模块
- HTTP 调用集中在 `api/` 下按领域拆分文件，统一返回 `ApiError` 并由页面侧处理
- 跨页状态通过 `store/` 中的 Signal 配合 `use_context_provider` 注入，页面用 `use_context` 消费
- 可复用 UI 逻辑封装为 `components/` 下的 Dioxus 组件或 `hooks/` 下的自定义 Hook
- 全局副作用（Toast、Theme、移动端断点）在 `App` 根组件中集中提供，页面仅消费
- 前后端 DTO/枚举/错误类型通过 common crate 共享，避免前后端定义不一致
