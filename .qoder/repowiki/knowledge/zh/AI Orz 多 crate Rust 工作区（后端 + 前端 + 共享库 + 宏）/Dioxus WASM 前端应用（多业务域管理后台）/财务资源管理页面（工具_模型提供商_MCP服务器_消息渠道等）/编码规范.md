- 每个资源页面由「列表组件 + 详情组件」两个文件组成，列表页通过 `Link` 跳转到 `FinanceXxxDetail { id }` 路由。
- 页面内状态统一用 `use_signal` 声明（loading、数据列表、表单字段、弹窗开关），并在 `use_effect` 中触发初始加载。
- 异步副作用统一通过 `spawn(async move { ... })` 执行，错误一律调用 `toast.error(&e)` 提示，成功则刷新列表或跳转。
- 删除等破坏性操作先设置 `pending_delete_id` 并打开 `ConfirmDialog`，在 `on_confirm` 中再真正调用删除 API。
- 新增/编辑操作通过 `Modal` 弹窗承载表单，提交后清空表单字段并 toast 提示，成功后重新拉取列表。
- 列表渲染使用 `table table-zebra table-pin-rows` 表格，每行以 `key: "{id}"` 绑定唯一键，启用/禁用状态用 `badge badge-success` / `badge badge-error` 区分。
