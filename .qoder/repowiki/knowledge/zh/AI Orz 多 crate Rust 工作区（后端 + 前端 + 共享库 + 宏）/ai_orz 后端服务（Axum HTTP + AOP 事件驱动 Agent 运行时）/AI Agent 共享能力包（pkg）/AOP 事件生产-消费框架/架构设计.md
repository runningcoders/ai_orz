模块以 `core/` 定义核心 trait 与调度逻辑（`Event`/`Consumer`/`Producer`/`Scheduler`/`AopMetricsHook`），由 `Registry` 集中管理消费者注册、事件发布、队列分配与 worker 启动；`queue/` 抽象出 `EventQueue` trait 并提供 `InMemoryEventQueue` 默认实现，支持按 `order_key` 分片、pending/in_progress 状态管理与 ack/nack 确认；`impls/` 目录预留 cron_trigger、message 等具体 Producer 扩展点。顶层 `mod.rs` 通过 `once_cell::sync::Lazy` 暴露全局单例 `REGISTRY`，并提供 `publish`、`init_all` 便捷入口。依赖方向单向：`registry` → `consumer`/`producer`/`scheduler`/`queue`/`metrics_hook`，业务层仅依赖 `pkg::aop` 重导出的 trait，不感知 domain/dal/dao。
