- 全局可共享状态通过 `std::sync::OnceLock` 或 `once_cell::sync::OnceCell` 持有，并以 `init_*` 函数在 `init_all` 中一次性设置，避免重复初始化。
- 请求级数据采用不可变结构体 + Builder 模式构造，提供 `to_builder()` 以便在调用链中增量扩展新上下文。
- 对需要并发访问的内存状态使用 `DashMap` 而非 `RwLock<HashMap>`，并在修改后立即释放借用（显式 `drop(entry)`）以避免长时间持锁。
- 状态变更通过 AOP 事件异步通知：同步方法内用 `tokio::spawn` 将事件推送到 `pkg::aop::publish`，保证不影响主流程性能。
- 日志字段通过 `#[derive(LogFields)]` 与 `#[log_field]` 属性声明，由宏自动生成 `create_log_span`，使字段列表成为单一数据源。
- 按日分片持久化统一采用 `{base_path}/{YYYYMMDD}.jsonl` 命名约定，通过 `DailyJsonlWriter` 抽象 append/read 操作供多个子系统复用。
