模块以 `mod.rs` 为入口，按业务子域拆分子模块：`aop`（AOP 队列统计与事件查询）、`backup`（备份创建/删除/列表/恢复）、`cron_trigger`（CRON 触发器的 CRUD 与暂停/恢复）、`logs`（日志统计与查询）、`seed`（跨领域 SeedSnapshot 导出/导入/diff）、以及顶层的 `task_list`/`task_progress`/`task_cleanup`/`health_metrics`/`aop_stats`。每个 handler 函数通过 `#[generate_http_handler]` 宏自动注册路由，请求参数与响应类型统一来自 `common::api`，业务编排委托给 `service::domain::{system, organization, finance, hr}` 等 domain 层，handler 仅负责参数解析、权限校验与结果转换。高危操作（备份、seed load/apply-default/delete）在路由层 `require_role_middleware(UserRole::Admin)` 基础上于 handler 内部二次校验 `SuperAdmin` 角色。`seed` 子模块还承担跨领域聚合职责，调用多个 domain 组装/应用 `SeedSnapshot`，并通过 `reqwest` 支持从 URL 抓取技能文件内容。
