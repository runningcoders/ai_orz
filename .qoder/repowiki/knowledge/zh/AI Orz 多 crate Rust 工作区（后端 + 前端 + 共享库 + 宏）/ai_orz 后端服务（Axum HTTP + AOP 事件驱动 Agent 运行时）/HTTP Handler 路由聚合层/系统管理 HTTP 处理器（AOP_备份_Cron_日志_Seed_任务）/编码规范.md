- 每个 HTTP 端点函数使用 `#[generate_http_handler]` 宏声明，并以 `_ctx: RequestContext, params: XxxRequest` 作为固定签名，返回值统一为 `Result<T>`。
- 子模块采用「按方法粒度拆分」的文件组织方式：每个 handler 独立一个 `.rs` 文件，并在子模块 `mod.rs` 中集中 `pub use` 暴露 handler。
- 对 SuperAdmin 敏感操作在 handler 内部通过本地 `check_super_admin(ctx)` 辅助函数二次校验角色，而非仅依赖路由中间件。
- handler 不直接访问数据库，而是通过 `crate::service::domain::xxx::domain()` 获取领域服务单例进行编排，保持 handler 薄且无状态。
- 分页/限流参数采用 `limit.unwrap_or(100).min(1000)` 这类默认值+上限截断的模式，防止恶意大查询。
- 可选查询参数使用 `Option<String>` 配合 `as_deref()` 与 `match s.to_lowercase().as_str()` 进行枚举化解析，未匹配时视为空过滤。
