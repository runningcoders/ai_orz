模块以 `mod.rs` 暴露单例化的 `HrDomain` trait（通过 `OnceLock<Arc<dyn HrDomain>>` + `init()`/`new()` 注入），并拆分子能力 trait：`AgentManage` 与 `SkillManage`，由 `HrDomainImpl` 统一实现。
- 依赖方向单向向下：本域仅依赖 `service::dal::{agent, skill, tool}` 的 DAL trait 与 `service::dao::{agent, skill}` 查询参数，不感知 HTTP/Handler；`RequestContext` 贯穿所有方法用于权限与上下文传递。
- `agent.rs` 实现 Agent 生命周期（CRUD、状态机 `transition_status`、入职就绪校验 `validate_onboard_readiness`）、工具包/技能包的按 tag 安装卸载（幂等）、以及 `resolve_agent` 的前台路由（优先 `feishu_reception` 角色，否则任意 Onboarded Agent）。
- `skill.rs` 实现 Skill CRUD、文件读写（含路径安全校验 `validate_skill_import_target_path`）、作者级权限检查、乐观锁更新、以及从源 Skill 到 Agent 副本的安装/卸载/重装覆盖逻辑。
- 测试通过 `#[cfg(test)] mod agent_test; mod skill_test;` 隔离引入，并使用 `domain::hr::new(...)` 注入 mock DAL 进行单元测试。
