本模块以经典的三层架构组织 src/service：
- domain/ 按业务域（hr、finance、organization、message、project、runtime、system）划分领域服务，每个子域暴露独立的 init() 与可选的 init_base_data() 异步初始化入口；
- dal/ 提供跨 DAO 的业务级聚合接口（如 agent、task、message 等），由对应 DAL 组合多个 DAO 完成 CRUD、混合搜索与统计；
- dao/ 按实体目录拆分具体存储实现（sqlite.rs / vector.rs / stats_duckdb.rs / http.rs 等），并通过 mod.rs 统一导出。
启动时由顶层 service::init() 严格按 dao::init_all → dal::init_all → domain::init_all 顺序执行，确保依赖方向单向向下；第二阶段 service::init_base_data() 仅调用 domain::init_all_base_data() 做幂等默认数据注入（目前为 system 域的 cron trigger）。测试文件与实现同目录并列，domain/dal/dao 各自维护独立 test 模块。
