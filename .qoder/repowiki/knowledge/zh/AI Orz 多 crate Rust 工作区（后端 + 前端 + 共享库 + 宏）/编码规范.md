- workspace 内所有 crate 通过 Cargo.toml members 声明并由根 Cargo.lock 统一锁定版本，新增子模块需同步注册到 members 列表。
- 前后端类型契约集中在 common crate 中定义（DTO、枚举、错误模型），后端与前端均通过 path dependency 引用，禁止各自重复定义。
- HTTP handler 通过 ai-orz-macros 的 #[generate_http_handler] + #[derive(Params)] + #[param(source = "path/query")] 从结构体注解自动生成路由与 LLM 工具参数，避免手写路由映射。
- 数据库变更以 migrations 目录下按时间戳命名的 SQL 脚本增量演进，SQLX 在编译期通过 .sqlx/ 缓存校验查询与 schema 一致性。
- 测试以独立 [[test]] 条目注册在根 Cargo.toml，每个测试文件对应一个端到端场景（如 a2a_flow_test、vector_degradation_test），由 CI 统一以 cargo test --test '*' 执行。
