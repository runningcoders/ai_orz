- 派生宏统一采用 `parse_macro_input!(input as DeriveInput)` 解析输入，再遍历字段属性匹配特定注解名（如 `is_ident("timestamp")`、`is_ident("log_field")`）。
- 对字段类型的判断封装为独立的 `is_option_string` / `is_string` 等辅助函数，基于 `syn::Type::Path` 的段名匹配而非字符串比较。
- 生成的代码通过 `quote! { ... }` 模板拼接，并按字段集合是否为空条件性地生成方法体（如当无 tag/metric 字段时省略对应方法）。
- 过程属性宏使用 `syn::meta::parser` 解析命名值参数（id/name/description/tags/neural），缺失必填参数时调用 `panic!` 给出明确错误信息。
- HTTP handler 生成器依据 path/query/body 的存在情况分四路分支生成不同签名的 axum handler，体现“按注解组合生成最优路由”的模式。
