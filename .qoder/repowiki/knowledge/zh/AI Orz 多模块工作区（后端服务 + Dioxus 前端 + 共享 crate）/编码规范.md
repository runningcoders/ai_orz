- HTTP 接口通过 ai-orz-macros 的 #[generate_http_handler] + #[derive(Params)] + #[param(source = "path/query")] 宏，一份结构体同时生成 handler 与 LLM 工具参数。
- 后端严格遵循 handlers → service(domain/dal/dao) → models 单向依赖，DAO 不调 DAO、DAL 不调 DAL、Domain 不调 Domain。
- 跨进程异步通信统一经由 src/pkg/aop 事件队列，producer/consumer 仅消费/生产事件，不直接耦合业务逻辑。
- common crate 集中存放前后端共享的 API DTO、枚举与错误类型，前端通过 common 而非后端路径引用这些类型。
- 数据库变更以 migrations/*.sql 文件形式提交，通过 sqlx 在启动或部署时应用。
