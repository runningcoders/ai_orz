本 crate 是独立的 proc-macro 库（`proc-macro = true`），仅依赖 `syn`/`quote`/`proc-macro2` 等编译期工具，不依赖后端 service 代码，通过 workspace 成员形式被其他 crate 引用。
- `lib.rs` 暴露四个入口：`#[derive(Params)]`（空实现，仅保留 `#[param(source=...)` 属性供扫描）、`#[generate_http_handler]`（根据 Params 结构体的 `path/query/body` 标注生成对应 axum handler，自动处理 path+query+body 混合、flatten query、空 params 无 body 等分支）、`#[register_handler_tool]`（将函数包装为 `BuiltinToolFactory`，用 `schemars::schema_for!` 生成 JSON Schema 并借助 `ctor` 在启动时注入全局 tool registry）、`#[derive(LogFields)]`（委托给子模块）。
- `stats_event.rs`：`#[derive(StatsEvent)]` 扫描 `#[timestamp]`/`#[tag]`/`#[metric]`/`#[event_type]` 注解，生成 `StatEvent` trait 实现，用于指标上报。
- `log_fields.rs`：`#[derive(LogFields)]` 扫描 `#[log_field]` 注解，生成 `LogFields::create_log_span`，按字段类型选择 `%`/`?` 格式化输出到 tracing span。
- 依赖方向单向向外：宏只依赖 `common` crate 的 API/错误类型路径名（如 `common::api::ApiResponse`、`common::error::Error`、`common::enums::tool::*`），运行时由调用方 crate 提供具体实现；宏自身不含业务逻辑。
