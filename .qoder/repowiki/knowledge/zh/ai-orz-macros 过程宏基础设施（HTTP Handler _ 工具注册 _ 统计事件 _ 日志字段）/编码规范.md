- Params 结构体通过 `#[param(source = "path"|"query"|"body")]` 标注字段来源，其中 `query` 字段可叠加 `#[serde(flatten)]` 表示整段 query 反序列化到嵌套结构。
- `#[generate_http_handler]` 生成的 handler 统一返回 `axum::Json(common::api::ApiResponse<Output>)`，并通过 `Extension(RequestContext)` 注入上下文。
- `#[register_handler_tool]` 要求必须提供 `id`/`name`/`description`/`params` 四个属性，并使用 `#[ctor::ctor]` 在模块加载时调用 `get_registry().register_builtin_factory(...)` 完成自注册。
- StatsEvent 结构体强制要求恰好一个 `#[timestamp]` 字段，可选 `#[tag]` 与 `#[metric]` 字段分别生成 tags_json 与 metrics_json 方法。
- LogFields 对 `Option<String>` 使用 `%` Display 格式化为空串，对普通 `Option<T>` 使用 `?` Debug 格式，其余字段默认使用 `%` Display。
