模块以 `mod.rs` 为中心，集中维护一个通过 `OnceLock<Client>` 初始化的全局 `reqwest::Client`，并通过 `build_request` + `current_config().api_url()` 统一拼接后端地址；对外暴露 `api_get/api_post/api_put/api_delete/api_get_or_default/api_get_text/api_post_multipart` 等通用方法，所有调用统一走 `ApiResponse<T>` 反序列化、`handle_unauthorized` 401 跳转登录、`parse_error_response`/`network_err` 统一转为 `ApiError { http_status, error_code, message }`。WASM 环境下 multipart 上传通过 `web_sys::Request` + `window.fetch_with_request` 绕过 reqwest 限制。分页参数通过 `build_pagination_url` 和 `build_query_string` 两个工具函数构造。各业务域文件（auth、project、finance、hr、message、organization、system、background_task、log_stats、seed）仅依赖 `super::*` 中的通用方法与 `common::api` 中的请求/响应类型，形成「通用层 → 领域层」的单向依赖。
