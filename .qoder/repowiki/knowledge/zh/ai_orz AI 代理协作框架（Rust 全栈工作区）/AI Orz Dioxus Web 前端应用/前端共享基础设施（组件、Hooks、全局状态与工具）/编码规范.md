- 全局状态通过 `use_context_provider` 在根组件注册，并以 `use_xxx()` 形式的 Hook 在子组件中读取，如 `use_auth_state`、`use_toast`、`use_theme`。
- 组件采用 Dioxus `#[component]` + `#[derive(Props)]` 结构体定义 Props，并使用 `rsx!` 宏返回 Element。
- 浏览器存储访问统一通过 `utils::local_storage()` 封装 `web_sys::Storage`，避免直接调用 `window().local_storage()`。
- 主题与 Toast 等全局能力采用 provide/consume 模式：提供端返回控制器结构体（如 `ThemeController`、`ToastState`），消费端通过同名 `use_*` Hook 获取。
- 认证与主题等持久化信息写入 localStorage 时忽略错误（`let _ = storage.set(...)`），保证 UI 不因存储失败而崩溃。
- 模块入口 `mod.rs` 仅做子模块声明与公共 API 的 `pub use` 重导出，保持对外接口扁平化。
