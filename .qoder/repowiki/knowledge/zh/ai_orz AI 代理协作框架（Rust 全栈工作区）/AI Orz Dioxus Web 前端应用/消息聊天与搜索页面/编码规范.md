- 所有 UI 状态通过 `use_signal` 声明并在组件顶部集中注册，再在条件分支中读取，避免早期 return 导致 hooks 槽位错位。
- 网络请求统一用 `spawn(async move { ... })` 执行，成功/失败路径均设置 loading 标志并通过 `use_toast()` 反馈错误信息。
- 消息列表渲染前调用 `group_messages_by_date` 分组，并以 `message_id` 作为 key，日期分隔符使用稳定 key 避免切换会话时重排。
- SSE 回调通过 `Closure::wrap` 包装并保存在局部变量中，在 `use_drop` 中显式 `set_onmessage(None)` 并 `close()` 释放资源，防止内存泄漏。
- 对可能失败的浏览器 API（如 `EventSource::new`、`FormData::new`）一律使用 `match`/`ok()` 处理而非 unwrap，失败时降级并 toast 提示。
- 聊天输入区逻辑抽取为独立函数 `chat_input_area`，由项目对话框与默认对话框两个分支复用，避免 rsx 重复。
