模块以 `mod.rs` 为入口，将每个系统子功能拆分为独立文件（aop、backup、health、logs、seed、tasks、triggers），每个文件导出一个顶层 `#[component]` 函数（如 `SystemHealth`、`SystemLogs`、`SystemTasks` 等），统一通过 `AppLayout` 布局组件包裹。所有页面均依赖 `crate::api::*` 下的后端 API 客户端进行异步请求，使用 `crate::store::toast::use_toast()` 做用户反馈，并通过 `crate::components::{gauge, charts, modal, state}` 等共享 UI 组件渲染图表与弹窗。轮询刷新采用两种模式：`use_effect + spawn + loop + sleep_ms`（health/aop）或 `use_future + gloo_timers::TimeoutFuture`（tasks），wasm 环境下通过本地 `sleep_ms` 封装 `js_sys::Promise` + `web_sys::setTimeout` 实现定时。状态管理统一使用 Dioxus `Signal`，列表/筛选/分页等交互在组件内完成，无全局 store。
