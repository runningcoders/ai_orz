- 每个集成测试函数以 `#[sqlx::test]` 标注，并在函数体开头调用 `init_full_test_env(pool.clone()).await` 后再构造 `TestApp`。
- 需要鉴权的请求统一通过 `TestApp` 的 `*_with_jwt` 方法发送，JWT 值通过 `Cookie: ai_orz_jwt=...` 头传递。
- 响应断言优先使用 `assert_api_ok` / `assert_api_error` 检查 HTTP 状态码与业务 envelope 的 `code` 字段，而非手写 `assert_eq!`。
- 测试数据通过 `factories::create_test_*` 与 `bootstrap_and_login` 生成，并使用 `uuid::Uuid::now_v7()` 拼入名称避免冲突。
- SSE 相关测试使用 `get_with_jwt_collect_sse_events` 收集事件，并以 `max_events` + `max_wait` 超时控制等待边界。
- 测试间数据隔离依赖全局 Storage 单例 + 唯一 ID，不在测试前清理数据库，而是靠命名空间隔离。
