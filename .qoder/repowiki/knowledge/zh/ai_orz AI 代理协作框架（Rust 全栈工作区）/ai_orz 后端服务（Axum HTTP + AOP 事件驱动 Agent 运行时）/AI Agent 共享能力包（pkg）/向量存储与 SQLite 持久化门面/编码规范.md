- 所有向量后端均实现 `vector.rs` 中定义的 `VectorStore` trait，通过 `Arc<dyn VectorStore>` 注入，使后端可在运行时按配置切换。
- 后端构造采用 `new()`（读配置路径）与 `with_path()`（测试专用指定路径）双构造函数模式。
- 集合级元数据与数据分离持久化：HnswStore 将 collection 数据与 `collections_meta.bincode` 分开存储，并通过 dirty flag + 后台任务异步落盘。
- 搜索结果统一封装为 `VectorSearchHit { row: VectorRow, distance }`，其中 `VectorRow.vector` 字段在后端不返回原始向量时置为空，由上层按需重新向量化。
- 错误处理统一通过 `common::error::Result` 返回，并在关键路径使用 `tracing::warn!` 记录非致命错误而不中断流程。
