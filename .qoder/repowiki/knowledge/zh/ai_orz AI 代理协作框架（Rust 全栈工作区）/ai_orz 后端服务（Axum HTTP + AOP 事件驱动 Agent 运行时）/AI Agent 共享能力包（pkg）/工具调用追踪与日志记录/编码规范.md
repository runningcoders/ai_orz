- 数据模型统一派生 `Serialize`/`Deserialize`，并通过 `Default` 实现提供空值初始状态以便构造新条目。
- 日志持久化采用每日一个 `.jsonl` 文件的 append-only 模式，写入与读取均委托给 `DailyJsonlWriter`，本模块仅负责编排路径与过滤。
- 查询接口使用可选字段构成的 `ToolCallQuery` 结构体，匹配逻辑通过 `is_none_or` 链式组合实现“未指定即忽略”的过滤语义。
- 对外部协议工具（HTTP/MCP）的 trace 输入、输出、错误统一替换为 `[REDACTED]`，而 Builtin 工具保持原值用于调试。
- 工具 ID 在用于文件系统路径前通过 `validate_tool_id_for_trace_path` 校验，禁止包含 `/`、`\`、`.`、`..` 等危险字符。
