模块按 A2A 协议能力分层组织：`jsonrpc.rs` 作为统一入口 `POST /a2a`，校验 JSON-RPC 版本并依据 `method` 字段分发到 `send_task`、`get_task`、`cancel_task`；`agent_card.rs` 提供无需认证的 `GET /.well-known/agent.json` 能力发现；`callback.rs` 接收远程系统回调以同步任务状态与消息；`mapper.rs` 集中承担 A2A 协议实体（`A2aTask`/`A2aMessage`/`A2aArtifact`）与 ai_orz 内部模型（`ProjectStatus`/`Message`/`Artifact`）之间的双向转换，使 domain 层不感知 A2A 概念。依赖方向单向：handler → mapper → service/domain (`hr_domain`、`project_domain`、`message::domain`) → DAL，handler 层负责组合 agent 与 project 两个维度但不直接唤醒 agent（唤醒由 consumer 异步闭环）。配置通过全局单例 `crate::config::get()` 读取，请求上下文通过 axum `Extension<RequestContext>` 注入。
