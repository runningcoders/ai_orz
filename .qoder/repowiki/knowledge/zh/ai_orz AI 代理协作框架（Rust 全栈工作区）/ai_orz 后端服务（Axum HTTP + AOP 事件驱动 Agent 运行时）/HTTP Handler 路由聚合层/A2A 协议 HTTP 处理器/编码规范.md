- 每个 A2A 方法对应独立文件（`send_task.rs`、`get_task.rs`、`cancel_task.rs`），并在 `mod.rs` 中按 Task 进度顺序声明，便于增量开发。
- JSON-RPC 入口统一通过 `match req.method` 分派到 `dispatch_*` 辅助函数，参数经 `serde_json::from_value` 反序列化为强类型 Params 后再调用具体 handler。
- 错误处理统一返回 `common::error::Result<A2aTask>`，由入口统一包装为 `JsonRpcResponse::error`，业务侧使用 `bail_err!` 宏抛出带错误码的错误。
- A2A ↔ 内部模型转换集中在 `mapper.rs` 的纯函数（如 `build_a2a_task`、`project_status_to_a2a_state`、`extract_text_from_a2a_message`），handler 仅做编排不内联转换逻辑。
- 需要认证的路由通过 axum `Extension<RequestContext>` 提取 `uid()` 等上下文，未登录时返回 `InvalidRequest` 或 `not_found` 错误。
- 回调与外部事件通过 tags 记录同步计数（`A2A_SYNCED_MSG_COUNT_PREFIX`），利用 tag 前缀实现幂等增量同步。
