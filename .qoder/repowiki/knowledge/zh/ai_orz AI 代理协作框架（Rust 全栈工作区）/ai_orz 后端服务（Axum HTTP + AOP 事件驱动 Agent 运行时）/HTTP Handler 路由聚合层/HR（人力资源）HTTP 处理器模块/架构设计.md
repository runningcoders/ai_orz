模块以 `mod.rs` 为入口，导出 `agent`、`skill` 两个子模块，每个子模块再按 HTTP 方法粒度拆分为独立文件（如 `create_agent.rs`、`get_agent.rs`），并在各自 `mod.rs` 中集中 `pub use` 暴露 handler。
- 每个 handler 函数使用 `#[generate_http_handler]` 宏自动完成请求解析与响应序列化，通过 `#[register_handler_tool(...)]` 同时向 AI 工具系统注册元数据（id/name/description/params/tags）。
- Handler 仅负责参数校验、上下文提取（从 `RequestContext` 取 `uid()`）、调用领域层 `service::domain::hr::domain().agent_manage()/skill_manage()` 以及将领域模型转换为 `common::api::*` DTO；不直接访问数据库。
- 共享响应转换逻辑集中在 `skill/response.rs` 等文件中，通过 `pub(super)` 供同模块内 handler 复用。
- 依赖方向单向：handler → domain service → DAL/models，跨域协作时通过 `finance_domain()` 等全局 accessor 获取其他领域服务。
