- 每个 HTTP 端点独立一个文件，文件名采用动词+名词形式（如 create_agent.rs、get_agent.rs），并在对应子模块 mod.rs 中集中 pub use 暴露 handler。
- Handler 函数统一签名 `(ctx: RequestContext, params: XxxRequest) -> Result<XxxResponse>`，通过 `#[generate_http_handler]` 宏自动绑定路由与序列化。
- 对外暴露的 handler 同时添加 `#[register_handler_tool(id=..., name=..., description=..., params=..., tags=...)]` 以便被 AI 工具系统发现。
- 业务逻辑委托给 `service::domain::hr::domain().xxx_manage()` 领域服务，handler 本身只做参数组装、错误处理与 DTO 转换。
- 领域模型到 API DTO 的转换集中在子模块内的 `response.rs` 或同名转换函数中，通过 `pub(super)` 限制可见性。
- 用户身份统一从 `ctx.uid()` 提取并做空值校验，失败时通过 `bail_err!(InvalidRequest, ...)` 返回错误。
