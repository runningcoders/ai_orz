本模块是应用 HTTP 层的聚合入口，顶层 `mod.rs` 仅声明各领域子模块（a2a、finance、hr、organization、project、system、user、health），不承载业务逻辑；每个子模块内部再按资源维度拆分（如 finance 下分 attachment/mcp_server/tool/message 等）。跨子模块的协作模式：
- 处理器文件使用 `ai_orz_macros::{generate_http_handler, register_handler_tool}` 宏将方法级处理函数同时暴露为 HTTP handler 与可被 Agent 调用的工具接口。
- 各子模块的 `mod.rs` 通过 `pub use <file>::xxx_handler` 重新导出由宏生成的 handler 函数名，形成统一的命名约定（`<verb>_<resource>_handler`）。
- 最外层 `handlers/mod.rs` 仅做模块声明，实际路由注册在更上层的 `Router` 构建代码中引用这些导出的 handler。
- a2a 子模块作为协议适配层，通过内部 mapper 将 A2A JSON-RPC 请求桥接到 finance/hr/project 等领域 handler，实现外部协议与内部领域的解耦。
