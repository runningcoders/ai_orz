- 处理器函数同时标注 `#[register_handler_tool(...)]` 与 `#[generate_http_handler]` 两个宏以完成工具注册与 HTTP 路由生成。
- 通过 `RequestContext.user_id` 获取当前登录用户，缺失时统一返回 `common::error::Error::bad_request("用户未登录")`。
- 领域对象读取失败时统一转换为 `common::error::Error::not_found("用户不存在")`。
- 响应构造时将空字符串字段（如 `display_name`、`email`）转为 `Option` 的 `None` 再放入 DTO。
- 角色枚举到显示名称的映射在多处重复使用 `Member→成员 / Admin→管理员 / SuperAdmin→超级管理员` 的 match 模式。
