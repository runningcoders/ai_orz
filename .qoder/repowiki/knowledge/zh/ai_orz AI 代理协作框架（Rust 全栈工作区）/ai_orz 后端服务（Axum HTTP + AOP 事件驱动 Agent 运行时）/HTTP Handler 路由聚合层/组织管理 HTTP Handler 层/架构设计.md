模块以 `mod.rs` 为入口，按功能划分为五个子模块：`auth`（登录/登出）、`organizations`（组织的 CRUD）、`organization_me`（当前用户所在组织信息）、`user`（用户管理）和 `initialize_system`（系统初始化后台任务）。每个 handler 文件对应一个 HTTP 端点，使用 `ai_orz_macros::generate_http_handler` 宏将异步函数自动注册为 HTTP 处理器；部分公开工具型 handler 额外使用 `register_handler_tool` 暴露给 Agent。Handler 仅负责参数解析与响应组装，业务逻辑全部委托给 `service::domain::{organization, finance, system}` 的 domain 层，依赖方向单向向下。`initialize_system.rs` 还实现了 `BackgroundTask` trait，将多步骤初始化封装为可轮询进度的后台任务并通过 `pkg::background_task::registry` 调度。各子模块的 `mod.rs` 统一 `pub use` 导出 handler 函数名，供上层路由集中挂载。
