- 每个 handler 文件定义一个 `async fn` 并使用 `#[generate_http_handler]` 宏自动注册为 HTTP 处理器，参数通过 `RequestContext` 与请求体/路径参数注入。
- 子模块的 `mod.rs` 集中 `pub use` 导出各 handler 函数名，由上层路由统一引用而非直接 import 具体文件。
- Handler 内部通过 `service::domain::xxx::domain()` 获取领域服务实例并调用其方法，不直接访问数据库或模型持久化。
- 错误处理统一返回 `common::error::Result`，缺失资源时使用 `Error::not_found`、参数非法时使用 `Error::bad_request` 等语义化错误构造器。
- 需要 Agent 调用的 handler 在函数上附加 `#[register_handler_tool(id = ..., name = ..., description = ..., params = ...)]` 元数据声明工具契约。
- 跨域编排类操作（如系统初始化）封装为实现 `BackgroundTask` 的结构体，通过 `registry().register(...)` 提交并由 registry spawn 执行，外部通过 task_id 轮询进度。
