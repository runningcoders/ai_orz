- 每个处理器以方法粒度拆分为独立 `.rs` 文件，并通过同名 `<verb>_<resource>` 函数实现核心逻辑
- 处理器文件顶部使用 `#[register_handler_tool(...)]` 宏声明路由路径与工具元信息，并由 `generate_http_handler!` 生成 axum handler
- 子模块 `mod.rs` 集中 `pub use` 重新导出各处理器生成的 `*_handler` 函数，对外暴露统一命名
- 领域内共享的响应结构体放在同目录 `response.rs` 中，由处理器模块按需引入
- 测试文件与对应处理器同目录放置（如 `*_test.rs`、`integration_test.rs`），便于按处理器维度验证
