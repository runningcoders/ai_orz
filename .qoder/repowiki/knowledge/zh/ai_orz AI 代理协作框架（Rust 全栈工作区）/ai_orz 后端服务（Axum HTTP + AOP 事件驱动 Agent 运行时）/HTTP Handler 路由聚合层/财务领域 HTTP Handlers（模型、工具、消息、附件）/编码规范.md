- 每个 HTTP 方法独立为一个文件（如 create_model_provider.rs、delete_tool.rs），并在对应 `mod.rs` 中通过 `pub use xxx::xxx_handler` 集中重导出。
- Handler 函数统一采用 `async fn handler(ctx: RequestContext, params: XxxParams) -> Result<XxxResponse>` 签名，并通过 `#[generate_http_handler]` 宏生成路由适配。
- 需要对外暴露给 Agent 的工具在 handler 上附加 `#[register_handler_tool(id = ..., name = ..., description = ..., params = ..., [neural], [tags = ...])]` 元数据完成工具注册。
- 领域调用通过 `crate::service::domain::*` 下的命名空间函数（如 `domain().model_provider_manage()`、`runtime::domain().tool_execution()`）进行，避免直接依赖基础设施。
- 子模块内共享的响应结构体放在同目录的 `response.rs`，单元测试以 `*_test.rs` 命名并通过 `#[cfg(test)] mod` 引入。
