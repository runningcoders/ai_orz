模块由四个核心文件构成应用启动骨架：`main.rs` 仅作为 `#[tokio::main]` 入口，调用 `ai_orz::run()` 避免 bin target 重复编译；`lib.rs` 暴露统一日志宏（`log_info!`/`log_warn!`/`log_error!`/`log_debug!`，支持无上下文与带 `RequestContext` 两种模式）和全局 `run()` 启动序贯：依次执行 `config::init` → `pkg::init_all` → `service::init` → `producer/consumer::init` → `service::init_base_data` → 安装 AOP 统计 Hook → `aop::init_all` → 构建 Router → `axum::serve`；`config.rs` 通过 `OnceLock<Arc<AppConfig>>` 提供全局配置单例，默认配置以 `include_str!` 编译时嵌入，首次运行自动写出到 `.ai_orz/ai_orz.toml`，并保证基础数据目录与日志目录存在；`router.rs` 使用 Axum `Router::nest` 按权限划分 public_routes（无需 JWT）、protected_routes（JWT + RequestContext + 可选角色校验），并按业务域拆分为 hr/finance/system/organization/project/task/user 等子路由函数，同时挂载 A2A 协议端点（agent.json、JSON-RPC、SSE subscribe、callback）及静态资源 fallback。依赖方向单向：main → lib(run) → config/pkg/service/producer/consumer/aop/router，router 仅依赖 handlers/middleware/common，不反向依赖业务实现。
