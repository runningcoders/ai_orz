模块以 `mod.rs` 为中心，定义三个核心 trait：`RuntimeMemory`（记忆 CRUD、混合搜索、知识图谱遍历）、`RuntimeAwakening`（`wake_agent_brain` / `awaken` / `sleep_and_settle`）、`RuntimeToolExecution`（按协议路由 MCP/Builtin/HTTP 工具调用及 trace 查询），并由单一结构体 `RuntimeDomainImpl` 通过组合注入的 DAL（`BrainDal`、`ToolDal`、`McpToolDal`、`AgentDal`、`CodexAgentDal`、`A2aAgentDal`、`ToolCallLogger`）实现这些 trait，再通过 `OnceLock<Arc<dyn RuntimeDomain>>` 提供全局单例访问。

- 子模块职责划分：`awakening.rs` 实现唤醒主流程与共享的 `run_think_loop`（含超时 300s、上下文压缩阈值检测、多轮 think + tool call 分发、`ThinkingScene::Awaken/Settle/Summary` 工具过滤）；`memory.rs` 仅做 DAL 透传并在写入 Trace 时补齐 `log_id/user_id/organization_id/task_id`；`tool_execution.rs` 负责协议路由、手动工具授权校验（绑定/神经标签/已安装包 OR 语义）以及 MCP 错误归一化；`busy_guard.rs` 提供 RAII 守卫确保 Busy/Resting 状态在任意返回路径释放为 Idle；`tool_call_query.rs` 集中处理查询作用域合并与限制。
- 依赖方向单向向下：本层只依赖 `service/dal/*`、`models/*`、`pkg/tool_tracing`、`pkg/agent_runtime_state`，不反向被 DAL 引用；上层通过 `domain()` / `init()` 获取单例或测试用 `new_with_all` 注入构造。
