模块以 `mod.rs` 中的 `SystemDomain` trait 为聚合根，通过 `OnceLock<Arc<dyn SystemDomain>>` 暴露全局单例，由 `init()` 注入 `CronTriggerDal`、`BackupDal`、`LogQueryDal` 三个 DAL 抽象；`SystemDomainImpl` 同时实现 `CronManager`、`BackupManager`、`LogQuery`、`AopMonitor`、`AopStats` 五个子能力 trait，将调用转发到对应 DAL 或 `pkg::aop` 全局注册表。
- `aop_monitor.rs`、`aop_stats.rs` 作为独立子模块分别实现 AOP 监控与统计接口，其中 stats 通过模块内 `OnceCell` 获取外部设置的 `AopStatsCollector`。
- `seed/` 是纯工具箱子模块（不持有 DAL），按职责拆分为：`defs.rs` 定义 `SeedSnapshot`/`DiffEntry` 等 JSON Schema 结构；`diff.rs` 提供纯函数 diff 算法与敏感字段占位符解析（`PENDING_INPUT`/`INHERIT_CURRENT`/`RANDOM_GENERATE`）；`store.rs` 基于 `AppConfig.base_data_path/seeds` 做 .json 快照文件 CRUD；`embedded.rs`、`default.rs`、`default.json` 提供编译期内嵌默认技能模板与初始数据；`skills/TEMPLATE_*` 存放可被嵌入的技能 Markdown 模板。
- 依赖方向单向向下：domain → DAL 抽象 / `pkg::aop` / `common`，seed 子模块仅依赖 `common` 与文件系统，避免循环依赖。
