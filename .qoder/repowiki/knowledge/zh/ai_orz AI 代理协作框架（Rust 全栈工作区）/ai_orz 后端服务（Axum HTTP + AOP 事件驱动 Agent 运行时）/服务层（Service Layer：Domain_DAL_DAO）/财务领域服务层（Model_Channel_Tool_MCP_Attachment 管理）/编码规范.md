- 每个子领域以独立文件实现对应 Manage trait，并在 `mod.rs` 中声明 trait 定义与 `FinanceDomainImpl` 聚合方法，形成「trait 定义集中 + 实现分散」的结构。
- 所有领域方法签名统一接收 `RequestContext` 作为首参，并通过 `ctx.to_builder().agent_id(...).build()` 或 `enrich_ctx!` 宏派生上下文后再下钻到 DAL。
- 对外返回敏感配置时统一调用 `McpServer::redacted_for_management` 进行脱敏，更新时通过 `merge_redacted_config` 将 `REDACTED_CONFIG_VALUE` 占位符替换为原值。
- 写操作前执行领域级策略校验（如 Tool 的 protocol/control_mode 约束、internal 标签工具不可绑定 Agent、Attachment 文件名/内容/大小/MIME 校验），校验失败通过 `bail_err!` 抛出 `InvalidRequest` 等错误码。
- 测试文件采用 `<module>_test.rs` 命名并与源文件并列放置，通过 `#[cfg(test)] mod xxx_test;` 在 `mod.rs` 中条件引入。
- DAL 依赖通过 `Arc<dyn XxxDal>` 注入到 `FinanceDomainImpl`，生产由 `init()` 从全局 `dal()` 获取，测试由 `new()` 传入 mock/stub 实现，便于隔离。
