应用由 `src/lib.rs::run()` 按严格顺序装配：先加载配置并调用 `pkg::init_all` 初始化日志/存储/JWT/工具注册等基础设施，再依次初始化 service 层、producer/consumer（将业务生产者/消费者注册到 AOP 事件总线）、第二阶段幂等基础数据注入、安装 AOP 统计 Hook 并启动 AOP 调度器，最后通过 `router::create_router` 组装 Axum Router 并监听 TCP。HTTP 请求经 `middleware` 的 JWT 认证与 `request_context_middleware` 注入 RequestContext 后进入 `handlers` 各域处理器，处理器调用 `service` 层的 Domain/DAL/DAO 完成业务逻辑；读写操作产生的领域事件通过 `models::events` 经 `producer` 发布到 AOP 队列，再由 `consumer` 中按角色分发的消费者异步消费，形成“同步 HTTP → 异步事件”的双通道架构。跨子模块的共享契约集中在 `models`（实体/Po/事件类型）和 `pkg`（AOP 核心、存储抽象、工具注册、JWT、日志宏），所有子模块均依赖这些公共接口而非直接耦合实现。
