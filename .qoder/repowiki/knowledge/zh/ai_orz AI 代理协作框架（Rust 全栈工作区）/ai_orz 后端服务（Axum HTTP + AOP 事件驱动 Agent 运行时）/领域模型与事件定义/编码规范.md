- 每个业务实体采用「业务实体 + Po」双层结构：业务实体持有 `po: XxxPo` 字段并提供 `from_po` / `into_po` / `id()` / `status()` 等只读访问器，Po 负责持久化字段与 `new` 构造。
- Po 结构体使用 `#[derive(Debug, Clone, Serialize, Deserialize, FromRow)]` 并配合 `sqlx::types::Json<T>` 存储 JSON 列，复杂配置通过独立的 `*Config` 结构体承载。
- 可序列化的枚举统一使用 `#[serde(tag = "...", rename_all = "snake_case")]` 进行判别式序列化（如 ExternalAgentConfig、ThinkResult、ChatMessage）。
- 运行时可变配置（如 AgentRuntimeConfig）通过 `default` 默认值 + `from_json` / `to_json` 方法在 JSON 字符串与结构体之间互转，并提供 install/uninstall/has 等幂等方法。
- 事件类型集中在 `events/` 子模块，每个事件实现 `crate::pkg::aop::Event` trait，并通过 `events/mod.rs` 统一 re-export，事件 ID 使用 `uuid::Uuid::now_v7()` 生成。
- 向量检索能力通过实现 `Vectorizable` trait 注入到任意实体，由实体自行决定 `vectorize_text` 的字段组合与 `vector_collection` 集合名。
