- 所有跨模块共享的数据契约（DTO、枚举、错误模型、配置）集中在 `common` crate，并通过 feature flags 控制后端/前端/测试的可选集成能力
- HTTP API 参数与 LLM 工具调用共用一份结构体定义，由 `ai-orz-macros` 的 `#[generate_http_handler]` 与 `#[derive(Params)]` 自动派生 axum handler 与参数提取逻辑
- 后端严格遵循 Adapter→Domain→DAL→DAO 四层单向依赖，外部协议数据仅在适配层转换后进入 Domain，不污染内部事件中心
- 数据库变更通过 `.sqlx/` 中的时间戳命名迁移脚本管理，构建期由 SQLX 校验 SQL 哈希一致性
- 集成测试通过 `[[test]]` 段在根 `Cargo.toml` 集中注册，统一基于 `TestApp` 工厂与环境初始化覆盖端到端场景
