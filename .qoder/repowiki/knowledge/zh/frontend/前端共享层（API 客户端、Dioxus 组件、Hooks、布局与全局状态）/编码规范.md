- HTTP 请求统一通过 `api::api_get/api_post/api_put/api_delete` 等封装函数发起，所有接口返回 `Result<T, ApiError>`，由调用方自行处理错误。
- 401 响应在 `handle_unauthorized` 中集中处理：清除登录态并重定向到 `/login`，避免在各业务 API 中重复判断。
- 表单输入先以字符串形式保存在 `use_signal` 中，提交时通过纯函数（如 `build_create_request`、`parse_optional_json`、`parse_comma_list`）解析并校验，便于单测覆盖。
- 全局状态使用 Dioxus `Signal` + `use_context_provider` 提供（如 AuthState、ThemeController），子组件通过 `use_context` 读取，避免 props 透传。
- 认证状态持久化仅保存标志位与角色到 localStorage（HttpOnly Cookie 中的 JWT 不由前端持有），刷新后通过 `AuthState::restore` 恢复内存信号。
- 组件与模块均通过 `mod.rs` 显式 re-export 公共类型（如 `SearchableSelect`、`ChatSidePanel`、`use_resource`），保持调用方 `use crate::xxx::Yyy` 的稳定入口。
