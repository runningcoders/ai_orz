本模块为 Dioxus 0.7 WASM 前端 `pages/finance` 下的业务页面集合，通过 `mod.rs` 统一导出各子页面组件（tools/tool_detail、mcp_servers/mcp_server_detail、message_channels/message_channel_detail、model_providers/model_provider_detail、attachments/attachment_detail、tool_call_entries），由上层路由注册后挂载到 AppLayout。

- 每个资源遵循「列表页 + 详情页」成对组织：列表页负责 CRUD 入口、筛选/搜索、启用/禁用/删除等操作；详情页承载只读展示、调试调用（如 tool_detail 的 debug_call_tool）或统计面板（ToolStatsPanel）。
- 数据获取集中在组件内：使用 `use_signal` 维护本地状态，`use_effect` 在挂载时触发异步加载，并通过 `spawn(async move { ... })` 调用 `crate::api::finance::*` 中的 HTTP 客户端函数，错误统一经 `use_toast()` 提示。
- 跨模块复用：UI 骨架来自 `components/state::{Loading, EmptyState}`、`components/modal`、`components/confirm_dialog`；样式基于 Tailwind CSS v4 + DaisyUI v5；类型定义（DTO、枚举）来自 `common::api` / `common::enums`，保证前后端契约一致。
- 搜索与过滤采用「三场景切换」策略（tools.rs）：无关键词+无过滤走 list_tools，有过滤走 query_tools，有关键词走 search_tools，并用 `search_request_id` 版本号丢弃过期请求结果，避免竞态。
- 新增的工具调用记录页（tool_call_entries.rs）以列表+Modal 形式展示 call_id/agent_id/tool_id 等多维查询结果，并支持点击行拉取详情，为 ChatSidePanel 工具调用 Tab 复用进程详情提供数据源。
