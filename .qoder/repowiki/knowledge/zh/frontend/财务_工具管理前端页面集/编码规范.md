- 每个页面组件内部用 `use_signal` 声明本地状态（loading、列表数据、弹窗开关、表单字段），并在 `use_effect` 中发起首次异步加载。
- 异步副作用统一通过 `spawn(async move { ... })` 执行，成功更新信号、失败调用 `toast.error` 提示，形成一致的异常处理路径。
- 列表页普遍采用「列表卡片 + 顶部操作栏」布局，使用 DaisyUI 的 `table table-zebra table-pin-rows` 渲染表格，并以 `badge badge-success/badge-error` 区分启用/禁用状态。
- 危险操作（删除）一律先设置 `pending_delete_id` + `show_delete_confirm = true`，由 `ConfirmDialog` 二次确认后在回调中真正调用删除 API。
- 创建/编辑类操作通过 `Modal` 或 `CreateHttpToolModal` 弹窗完成，提交成功后重置表单字段并重新拉取列表刷新 UI。
- DTO 与枚举全部从 `common::api` / `common::enums` 导入并使用其 `from_i32` / `From` 实现进行 i32↔枚举转换，避免在页面层硬编码数值。
