- DTO 与枚举按领域拆分为独立文件（如 agent.rs、project.rs、tool.rs），并在 `api/mod.rs` / `enums/mod.rs` 中集中 re-export，便于上下游按模块引用。
- 每个 DTO 文件配套同名 `*_test.rs` 单元测试文件，测试通过 `#[cfg(test)]` 条件编译隔离。
- 配置结构体统一使用 `serde(default)` 标注可省略字段，并为每个配置段提供独立的 `Default` 实现和私有 `default_*` 构造函数。
- 错误处理统一通过 `common::error` 模块的 `ErrorCode` + `ErrorType` + `ErrorField` 三元组表达，并使用 `bail_err!`/`ensure_err!`/`err!` 宏抛出，而非裸 `anyhow::Error`。
- 对外部可选依赖一律通过 Cargo feature + `#[cfg(feature = "...")]` 条件编译引入，保证 common crate 在无 feature 时保持最小依赖面。
- 路径构造集中在 `AppConfig` 上提供 `db_path()`、`attachments_dir()`、`artifact_project_dir()`、`skill_content_path()` 等方法，调用方不直接拼接字符串路径。
