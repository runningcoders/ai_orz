## 一、目标

| 问题 | 方式 |
|------|------|
| think_loop 退出条件分散（轮次/超时/溢出/取消各自一套 if），难扩展难维护 | 抽取通用 Policy trait + Metrics，统一 evaluate 入口；策略可嵌套组合 |
| 5 类退出条件优先级混乱，命中多个时取哪个不明确 | map_triggered_to_result() 统一优先级：用户取消 > 上下文溢出 > token 预算 > 轮次 > 超时 |
| 用户取消思考无贯穿链路（think_loop 每轮感知不到） | AgentThinkRuntime 持 Arc\<AtomicBool\> cancel_flag，构造 UserCancelPolicy 注入策略组；cancel-thinking 接口翻转 AtomicBool |
| 前端无法实时查看思考进度（轮次/token/场景/trace_id） | AgentThinkRuntime 持 RwLock\<ThinkRuntimeSnapshot\>，think_loop 每轮 report_round 上报；runtime-status 接口读取快照 |
| 设计文档推荐 CancellationToken（tokio_util），新增依赖成本高 | 偏差采用 Arc\<AtomicBool\>（功能等价，零新依赖） |
| 策略声明式写法不友好（手工 new 嵌套 PolicyGroup） | 提供 PolicyBuilder 链式 API：with().with().build()（And）/ or()（Or） |

收敛一句话：策略引擎框架化 + AgentThinkRuntime 贯穿（cancel+快照）+ think_loop 接入，退出条件统一管理、前端实时可见、用户取消贯穿全程，零新依赖。

## 二、架构思路

```
┌─────────────────────────────────────────────────────────────┐
│ pkg/policy/ （纯框架层，零业务感知）                         │
│  ├─ Policy trait: id/name/condition_desc/required_metrics   │
│  │           / evaluate(&Metrics) -> Vec<String>            │
│  ├─ Metrics: HashMap<String, Value> 封装 + 链式 with()      │
│  ├─ PolicyGroup: 嵌套 And/Or 组合，自身实现 Policy           │
│  ├─ PolicyBuilder: 链式 with + build(And) / or(Or)          │
│  └─ builtin.rs 5 内置策略：                                  │
│      MaxRounds / Timeout / ContextOverflow                  │
│      / UserCancel(Arc<AtomicBool>) / TokenBudget            │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ AgentThinkRuntime（pkg 状态层）                             │
│  ├─ cancel_flag: Arc<AtomicBool>  → 注入 UserCancelPolicy   │
│  ├─ snapshot: RwLock<ThinkRuntimeSnapshot>                  │
│  │   (agent_id, trace_id, scene, round/max_rounds,          │
│  │    tokens x3, tool_call_count, status, started_at)       │
│  ├─ report_round(): think_loop 每轮写入快照                  │
│  ├─ cancel(): 翻转 AtomicBool + snapshot.status=Cancelled   │
│  └─ snapshot(): 读快照（runtime-status 接口用）              │
│                                                             │
│  StateManager 扩展方法：                                     │
│   set_think_runtime / clear_think_runtime                   │
│   cancel_thinking / get_think_runtime_snapshot              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ think_loop 接入（4 调用点：awaken/settle/summary/intent）   │
│  1. 创建 AgentThinkRuntime + 挂载到 StateManager            │
│  2. build_policy_for_scene(agent, scene, cancel_flag)       │
│     → PolicyBuilder: UserCancel + MaxRounds + Timeout (Or)  │
│  3. 每轮循环结束：                                           │
│     ├─ Metrics::new().with(round_number).with(elapsed)...  │
│     ├─ policy.evaluate(&metrics) → 命中？→ 提前退出         │
│     │  → map_triggered_to_result（优先级映射）               │
│     └─ think_runtime.report_round(快照上报)                 │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              BusyGuard Drop → clear_think_runtime + set_idle
```

## 四、分发点速查表

| 分发场景 | 构造入口 | 策略组合（默认 Or 关系） |
|----------|----------|------------------------|
| awaken 正式执行 | awaken() 内 build_policy_for_scene(Awaken) | UserCancel + MaxRounds + Timeout |
| settle 沉淀 | sleep_and_settle() 内 build_policy_for_scene(Settle) | UserCancel + MaxRounds + Timeout |
| summary 总结退出 | awaken_for_summary() 内 build_policy_for_scene(Summary) | UserCancel + MaxRounds + Timeout |
| intent-analyze 前置理解 | analyze_input_intent() 内 build_policy_for_scene(IntentAnalyze) | UserCancel + MaxRounds + Timeout |
| 命中策略优先级 | map_triggered_to_result() | user_cancel → context_overflow → token_budget → max_rounds → timeout |
| 取消思考接口 | StateManager::cancel_thinking(agent_id) | 翻转 Arc\<AtomicBool\> + 写 snapshot.status=Cancelled |
| 查询运行时快照 | StateManager::get_think_runtime_snapshot(agent_id) | 读 RwLock\<ThinkRuntimeSnapshot\> 克隆返回 |
