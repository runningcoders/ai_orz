## 一、目标（为什么做）

沟通页面（chat.rs）当前只展示项目名称与消息流，缺失项目总览、进行中任务、执行计划/结果、产物等上下文；默认对话（无项目）模式完全没有侧栏信息，Agent/用户资料无处快速查看。后端 API 已全部就绪（`GET /projects/{id}` 支持 with_progress_summary / with_task_graph / with_artifacts）。

| 问题维度 | 解决方式 |
|---------|---------|
| 聊天页缺项目/任务/产物上下文信息，打断工作流跳转 | 新增 `ChatSidePanel` 右侧静态/抽屉面板，按对话模式动态组装 4-5 个 Tab |
| 默认对话（无项目）缺 Agent/用户信息入口 | 两种模式复用 Agent Tab；默认对话追加「我」Tab（当前用户资料） |
| 面板展开/收起状态刷新即丢 | 持久化到 localStorage key `chat_project_panel_open` |
| 侧栏内容缺实时刷新，进度变化需手动 F5 | 手动刷新按钮 + SSE 会话匹配命中后防抖 2s 自动刷新（refresh_tick 代际计数丢弃过期请求） |
| 项目 API client `get_project` 查询参数遗漏 `with_progress_summary` | `build_query_string` 补传该字段（DTO 已有，仅查询串遗漏） |

**收敛后效果**：项目对话中可快速浏览项目概况/任务进度/产物分组/负责人 Agent 而不离开聊天上下文；默认对话中可快速查看接待 Agent 与自己资料；面板纯只读（编辑/创建仍在各自详情页），保持职责单一。

## 二、架构思路（怎么做的）

纯前端组件分层：主容器 chat.rs 负责挂载/布局/状态（panel_open + refresh_tick），ChatSidePanel 组件内部按对话模式组装 Tab，每个 Tab 独立懒加载对应 API：

```
frontend/src/pages/message/chat.rs（挂载层，不变动数据结构）
  ├─ 新增：panel_open 信号（localStorage 读写）
  ├─ 新增：refresh_tick: u64（SSE 命中 + 手动刷新均 +1）
  ├─ Header 右侧：两种对话模式均追加「信息面板」切换按钮
  └─ 条件渲染 ChatSidePanel
       ├─ lg 及以上（桌面端）：hidden lg:flex w-96 flex-col border-l 静态列
       └─ lg 以下（移动端）：fixed inset-y-0 right-0 z-50 w-80 抽屉 + 背景遮罩
            + on_close 回调（移动端专用）

frontend/src/components/chat/chat_side_panel.rs（新增组件，约 700 行）
  ├─ use_effect([project_id, refresh_tick])：防抖 2s 后加载
  │    ├─ 项目模式：并行 get_project(with_progress_summary + task_graph + artifacts) + list_project_tasks
  │    └─ 默认模式：无需预加载（Agent/我 Tab 懒加载）
  ├─ active_tab: usize（tabs-boxed 小号样式；模式切换重置为 0）
  ├─ Tab 总览（仅项目）：状态徽标 + Markdown 描述 + 进度条 + 执行计划/结果 Markdown + Mermaid 任务图
  ├─ Tab 任务（仅项目）：列表 + 单任务展开（HashMap 缓存 get_task(with_artifacts)）
  ├─ Tab 产物（仅项目）：split_artifacts 分组（项目级 + 任务级分组）
  ├─ Tab Agent（复用）：agent_id 懒加载 get_agent，两种模式共用
  └─ Tab 我（仅默认）：get_current_user_info 懒加载 + settings 页面 Link
```

**关键边界（行为红线，回归必保）**：
1. **面板纯只读**：不含任务/产物创建、状态变更、用户资料编辑（这些操作仍在各自详情页/设置页完成）
2. **任务展开缓存策略**：首次展开才 `get_task(id, with_artifacts=true)`，命中 HashMap 不再请求；refresh_tick 变化时清空缓存（避免过期数据）
3. **refresh_tick 代际计数**：SSE 多次触发时 sleep 2s 后比对代际，过期请求结果直接丢弃（后到覆盖先到的反模式）
4. **任务负责人仅显示 Agent ID 文本**，不额外批量查 Agent 名称（避免 N+1，后续迭代可增强）
5. **Mermaid 图窄面板溢出**：沿用 MermaidDiagram 组件自带的 `overflow-x-auto`，不额外做面板自适应布局

## 四、分发点速查表（新增同类功能第一站）

### 4.1 新增 Tab 或切换 Tab 组装规则

| 模式 | 现有 Tab 序列 | 新增 Tab 时改动入口 |
|------|--------------|-------------------|
| 项目对话（project_id=Some） | 总览 / 任务 / 产物 / Agent | chat_side_panel.rs 根组件的 Tab 渲染 match 分支 + 数据加载分支；模式切换时 active_tab 默认值需考虑新增 Tab 偏移 |
| 默认对话（project_id=None） | Agent / 我 | 同上；默认对话不需预加载数据集 |

> 代码入口：[chat_side_panel.rs 根组件 fn body](frontend/src/components/chat/chat_side_panel.rs) 内 Tab 渲染段 + use_effect 数据加载段

### 4.2 新增「面板纯只读的 Link 跳转详情页」模式

现有 4 处跳转参考：任务行 → Route::TaskDetail；产物行 → Route::ProjectArtifactDetail；Agent 卡片 → Route::AgentDetail；「我」Tab 底部 → settings。新增详情跳转复用同一交互（Link 组件 + target=self）。

## 七、后续扩展路径（4 步模板）

> **核心不变量**：面板纯只读（红线 #1）；refresh_tick 代际丢弃过期请求（红线 #3）。读写分离，写操作一律跳转详情页完成。

1. **任务负责人 Agent ID → 名称**：任务列表每行按负责人 agent_id 批量 `get_agent`（N+1 需批量化或预埋入 list_project_tasks 返回字段），入口在 [chat_side_panel.rs Tab 任务段](frontend/src/components/chat/chat_side_panel.rs)
2. **新增「最近对话」Tab（默认模式）**：在 §四 4.1 默认模式分支追加 Tab，数据源 `list_recent_chats`（如后端尚未提供则新增 API 对齐）
3. **产物预览内嵌**：当前产物行仅 Link 跳转详情页；后续可支持常见格式（Markdown/图片/文本）内嵌预览 Modal，复用现有文件预览组件（如有）
4. **面板宽度用户可调**：在 panel_open 基础上追加 panel_width localStorage；桌面端侧栏左边缘拖拽（Dioxus onmousedown + mousemove 合成事件）
