## 一、修复目标（为什么做）

Agent 唤醒流程中发现 40+ 个问题，覆盖 5 大维度，按严重程度收敛：

| 问题维度 | 修复方式 |
|---------|---------|
| (a) 系统可用性致命（AOP 队列死锁、Agent 状态泄漏、TOCTOU 竞态、nack 自旋） | 阶段 1 优先修复：queue ack/nack 补调用、RAII guard、try_set_busy CAS、退避 sleep |
| (b) 数据一致性与 Trace 断链（call_id 伪造、trace_ref 丢弃、重复写入、ctx 丢失） | 阶段 2 修复：call_manual 返回真实 entry、移除重复 log、ctx 异步路径回填 |
| (c) 用户体验（消息链断链、SSE 泄漏、投递静默失败、跨 task 阻塞） | 阶段 3 修复：root_id 继承、客户端断开清理、投递失败返回错误、order_key 用 task_id |
| (d) 其他中等问题（trace_id 碰撞、stats 查询阻塞、think hang、死代码） | 阶段 4 修复：随机后缀、非致命 stats 查询、think 5min 超时、移除无效参数 |
| (e) 安全优化（工具错误脱敏、Agent 授权校验） | 阶段 5 修复：Builtin/Http 错误脱敏、call_manual 校验 agent 存在 |

**收敛后效果**：5 个阶段共 18 个 Task 全部闭环，Agent 唤醒流程可用性从"偶发卡死需重启"提升至"异常自恢复"。

## 二、架构思路（怎么做的）

按优先级 5 阶段递进，从致命到优化逐层收敛：

```
阶段 1 可用性（先活下来）
  ├─ AOP queue: ack/nack 补调用 + nack 退避 sleep
  ├─ Agent 状态: BusyGuard RAII + try_set_busy 原子 CAS
  └─ Consumer: Agent 不存在 not_found 避免无限重试
      │
      ▼
阶段 2 一致性（数据不丢）
  ├─ ToolCall: call_manual 返回 (Value, ToolCallEntry) → 真实 call_id
  ├─ ToolTracing: 移除 CoreTool::call 重复 log_call
  ├─ Context: ToolCallMessage 携带 ctx 字段 → consumer 回填
  └─ Event: record_event! 失败 log_warn + 任务状态检查优先
      │
      ▼
阶段 3 用户体验（用户感知）
  ├─ Message: root_id 继承父消息 → 链不断
  ├─ SSE: 客户端断开时 Rx drop 清理 → 无内存泄漏
  ├─ Delivery: 全渠道失败返回 Err → 触发 nack 重试
  └─ AOP order_key: task_id 优先 → 同 project 跨 task 不阻塞
      │
      ▼
阶段 4 中等问题（健壮性）
  ├─ Memory: trace_id 加 u16 随机后缀 → 无并发碰撞
  ├─ Agent: stats 查询失败 log_warn 跳过 → 不阻塞加载
  ├─ Awakening: think 加 5min 超时 → LLM hang 不卡 Busy
  └─ Runtime: 移除 user_profile 死代码 + get_recent_context 无效 task_id 参数
      │
      ▼
阶段 5 安全优化
  ├─ ToolExecution: Builtin/Http 错误脱敏 → 不暴露路径/配置
  └─ ToolExecution: call_manual_tool_for_agent 校验 agent 存在 → 授权不静默降级
```

**关键边界（行为红线，回归必保）**：
1. AOP worker 循环：on_event 成功后必须调 `queue.ack`，失败后必须调 `queue.nack` + 退避 sleep
2. Agent Busy 状态：任何路径下 `set_busy` 后必须保证 `set_idle`（BusyGuard RAII 覆盖）
3. Consumer 并发：`try_set_busy` 原子操作必须通过 CAS 语义保证同一 Agent 不被并发唤醒
4. ToolCall Trace：call_id 必须使用 LoggingDecorator 生成的真实 ID，不得现场伪造 UUID
5. Message 投递：所有渠道全部失败时必须返回 Err 触发 nack 重试，不得静默 Ok
