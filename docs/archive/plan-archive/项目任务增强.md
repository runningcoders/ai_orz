## 一、增强目标（为什么做）

Project/Task 详情接口缺两类关键可视化能力，且现有模式不支持"按需返回"导致大对象浪费带宽：

| 问题维度 | 解决方式 |
|---------|---------|
| (a) 任务依赖关系不可视 → 无法快速判断阻塞链路 | 新建通用 `pkg/utils/graph` 组件（Graph 抽象 + Mermaid Renderer），Domain 层按 Task.status 着色后按需注入 |
| (b) Project/Task 下 Artifact 列表无 API → 前端需要多次拼接查询 | Domain 层聚合 artifact_dal，按 `with_artifacts` option 注入实体，复用已有 `ArtifactDetail` DTO |
| (c) 大字段（Mermaid 图、长列表）每次全量返回 → 带宽浪费 | 统一按需模式：`with_task_graph` / `with_artifacts` query 参数，DTO 字段 `skip_serializing_if = "Option::is_none"` |
| (d) 图形能力仅适用于 Task → 未来知识图谱/Agent 依赖图需重写 | Graph/Node/Line 抽象 + GraphRenderer trait，Mermaid 仅一种实现，未来可扩展 PlantUML/DOT |

**收敛后效果**：1 个通用图形组件 + 2 个实体（Project/Task）按需扩展能力落地，新增"图形化展示"只需实现 GraphNodeData 转换 + 加 option 字段。

## 二、架构思路（怎么做的）

4 层递进，通用层与业务层严格解耦：

```
API/Handler（契约不变，加 option 参数 + 字段映射）
  │  GetProjectRequest 加 with_task_graph / with_artifacts
  │  GetProjectResponse 加 task_graph / artifacts（Option）
  │  Task 同：加 with_artifacts
  ▼
Domain 层（聚合编排，纯透传 → 按需注入）
  │  ProjectDomainImpl::get_project 不再纯透传 DAL
  │  → with_task_graph=true：调 task_graph::build_task_graph_mermaid
  │  → with_artifacts=true：调 artifact_dal.list_by_project
  │  Project 实体：task_graph: Option<String>, artifacts: Option<Vec<ArtifactDetail>>
  ▼
通用业务子模块（task_graph 转换层）
  │  [src/service/domain/project/task_graph.rs]
  │  输入 Vec<Task> → 输出 Graph（按 dependencies 建边）
  │  TaskStatus → category（Done→done / Doing→doing / Todo→todo）
  │  调用 MermaidRenderer::render
  ▼
通用基础组件（pkg/utils/graph，零业务依赖）
  ├─ types.rs: Graph / GraphNodeData(id,label,category) / GraphLine(from,to,label)
  ├─ renderer.rs: GraphRenderer trait + MermaidRenderer(LR/TD 方向)
  └─ 扩展点：GraphRenderer trait → 未来可加 PlantUmlRenderer / DotRenderer
```

**关键边界（行为红线，回归必保）**：
1. `pkg/utils/graph` 必须保持零业务依赖：禁止引用 Project/Task/任何 domain 类型
2. 按需返回模式：所有新增大字段一律 `Option<T>` + `skip_serializing_if`，未请求时不序列化、不查询
3. 状态着色：`TaskStatus::Done` → class `done`、`Doing` → `doing`、其他 → `todo`（category 命名固定，前端 CSS 依赖）
4. Artifact 复用原则：直接复用 `ArtifactDetail` DTO，禁止新建 `ArtifactSummary` 等重复结构
5. 跨项目依赖节点（边指向图外节点 ID）：MermaidRenderer 自动补出为 `(external) <id>` 节点，不得 panic 或丢边
