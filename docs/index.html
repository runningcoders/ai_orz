③ 知识库怎么组织

  • A-设计 · 为什么这么设计决策快照，写定后冻结；是「意图权威」
  • B-落地方案 · 要去哪规划与进度快照；无权威性，进度可能过期
  • C-知识 · 是什么代码现状百科 + RAG 原子卡；是「现状权威」
  • archive/ · 被什么取代历史归档，只进不出，不作为现状依据
  • docs/modules/ · 进入知识库主体15 个能力域模块，每模块下就是上面的 A / B / C 三层
冲突时以 C-知识 为准（代码即事实），并回头修 A-设计。三层都放在同一个模块目录下，按 15 个能力域划分。
