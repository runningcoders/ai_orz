## 简介
思维轨迹（think_trace / think_path）是 Runtime 的**一等产物**，与记忆并列：记忆回答「我记了什么」，轨迹回答「我怎么想的」。它以 thinking round 为最小可观测单元，append-only 落盘到按天 JSONL，可回放、可统计、可前端可视化。

## 一次唤醒的轨迹链路
触发（QQ / 飞书 / REST / A2A / 定时）→ 唤醒（Awaken 单阶段直接执行；IntentAnalyze 作为可选独立工具，不再强制前置）→ 小脑路由快判断 → `think_loop` 轮次循环 → `think_path` 阶段编排 → 轮级落盘 → `query_think_traces` 读回 → 前端时间线与轨迹图。

| 环节 | 落点 | 备注 |
|------|------|------|
| 轮次编排 | `src/service/domain/runtime/think_loop.rs` | 1,813 行；轮 = 一次完整「思考 → 动作 → 再思考」 |
| 阶段编排 | `src/pkg/think_path/` | 14 个文件 / 约 2,499 行 |
| 落盘出口 | `src/pkg/think_trace.rs` | 407 行；轮级 append-only |

## 认知架构分层
| 层 | 定位 | 关键形态 |
|------|------|----------|
| Brain（容器） | 聚合「模型能力 + 思考编排 + 记忆」 | 持有 model_provider、cerebellum、memories |
| Cortex（慢思考） | 多轮工具调用 + 上下文装配 + 收敛 | 受三层思考预算约束 |
| Cerebellum（快思考） | 首轮模型调用前的亚秒级预判 | 超时 800ms、置信阈值 0.85、失败静默跳过 |
| Reflex（反射弧） | 零 I/O 短路 | 命中即返回，不装载上下文 |

三层思考预算：单次唤醒累计总轮次（`max_thinking_rounds`，跨压缩周期共享池）、单任务跨唤醒累计唤醒次数（`max_thinking_depth`）、收尾总结轮次（`summary_max_rounds`）。

## 七相位与十分区
七相位 = Stimulus / Reflex / Triage / Prepare / Deliberate / Consolidate / Review。**相位是「被观测到的阶段标签」，不是执行顺序**：一次思考可以跳过多个相位，也可以在 Deliberate 里反复进出。

十分区 ContextKey = memory / tools / skills / runtime / business / prompt / budget / intent / knowledge / artifacts。这是**上下文分区口径**，不是存储分区。

## 两条 JSONL 两棵目录树
| 产物 | 路径 | 语义 |
|------|------|------|
| 记忆原始细节 | `agents/{agent_id}/memory/{YYYYMMDD}.jsonl` | 我记了什么 |
| 思考轨迹 | `agents/{agent_id}/think_trace/{YYYYMMDD}.jsonl` | 我怎么想的 |

两者共用同一套按天 JSONL 写入设施（`pkg/daily_jsonl`），但目录树不同、语义不同、生命周期不同；路径常量见 `src/pkg/paths.rs`。统计与归档时不可混为一谈。

## 查询与前端消费
查询走 `query_think_traces`，按 agent / project / task 作用域守门；前端由轨迹图工具与聊天侧的轨迹时间线、轨迹图视图消费（合计约 1,942 行），支持按轮次展开阶段与工具调用。

## 设计取向
- **append-only**：只追加不改写，纠错靠新增，保证历史可回放。
- **轮级粒度**：跨轮次汇总交给消费者，避免读侧重算。
- **落盘不阻塞主流程**：写轨迹失败不影响本轮回答。
- **作用域即权限**：查询不做「全库随便翻」。

## 结论
思维轨迹把「Agent 怎么想的」从不可见的过程变成**可查询的数据**，是调试、计费、评估与产品化的共同底座；它与记忆子系统共用基础设施但不共享语义，必须在口径上严格区分。
