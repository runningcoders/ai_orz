# 思考图引擎改造实施计划

> **For agentic workers:** 使用 subagent-driven-development 逐任务实施，任务间 review。步骤用 `- [ ]` 勾选跟踪。

**Goal:** 把 Awaken 主思考路径从「大 prompt 一次塞给模型」改造为完整思考图：意图识别 → 知识/技能检索 → 短聚焦装配 → 主执行 → 新发现识别 → 循环再检索/退出。

**Architecture:** 不新建引擎——`pkg/think_path` 已是图引擎（ThinkNode/ThinkBus/蓝图/预算护栏），改造 = 扩展 `legacy_awaken` 蓝图与节点。新增 3 节点（intent/retrieve/discover）、2 个总线分区（Intent/Knowledge）、1 个 run 级检索状态槽位；LLM 触碰点全部走 `ThinkBackend` 缝（测试不打模型红线）。

**Tech Stack:** Rust + async-trait + serde_json + 既有 ThinkPathEngine。设计快照见 `docs/design/thinking_graph_engine_design.md`（本计划的任务编号与设计 §3 对应）。

**验证基线：** 每任务 `cargo test -p ai-orz <模块>` + `cargo clippy -p ai-orz -- -D warnings` 全绿后 commit。全程禁止 skip hooks。

**分层红线：** 节点（domain 层）只经 `deps.domain`（RuntimeDomainImpl trait 方法）或 `crate::service::dal::*::dal()` 访问数据，禁止直调 dao；日志用 `crate::log_info!/log_error!`（模块名 `legacy_awaken`）；错误用 `common::error::err!`。

```rust
/// 检索产物（总线 ContextKey::Knowledge 分区的载荷）
///
/// retrieve 写入完整字段；discover 回环时先写入「新词 + 思考摘要」，
/// 由下一次 retrieve 覆写为完整产物——两写者按节点顺序串行，无并发。
#[derive(Debug, Default, Clone, serde::Serialize, serde::Deserialize)]
pub struct RetrievalPack {
    /// 本次实际用于检索的词（差集后的新词）
    pub query_terms: Vec<String>,
    /// 知识命中摘要行（每条一行，已截断）

    /// 命中的思维方法技能（category=thinking_method）

    /// discover 产出的上一轮思考摘要（首轮为 None）
    pub prior_thinking_summary: Option<String>,
}

/// run 级检索状态：跨节点累积，visited 去重的唯一真相
#[derive(Debug, Default, Clone)]
pub struct RetrievalState {

    pub queried_terms: Vec<String>,
    /// discover 已执行的循环次数（软预算，蓝图预算是硬护栏）
    pub discovery_rounds: usize,
}

/// discover 节点的模型输出契约
#[derive(Debug, Default, Clone, serde::Serialize, serde::Deserialize)]
pub struct DiscoveryOutcome {
    pub new_key_terms: Vec<String>,
    pub prior_thinking_summary: String,
}
```

```rust
pub fn legacy_awaken_blueprint() -> Result<ThinkPathBlueprint> {
    let mut bp = ThinkPathBuilder::new("legacy_awaken")
        .entry("intent")
        .node_with("intent", PhaseId::Triage, 0, "意图识别：产出结构化 IntentAnalysis")
        .node_with("retrieve", PhaseId::Prepare, 0, "知识+方法技能检索（机械，Top-K）")
        .node_with("prepare", PhaseId::Prepare, 0, "装配本轮 Prompt")
        .node_with("deliberate", PhaseId::Deliberate, 0, "执行一轮思考")
        .node_with("compact", PhaseId::Prepare, 0, "溢出压缩后重来")
        .node_with("force_compact", PhaseId::Prepare, 0, "轮次耗尽压缩退出")
        .node_with("discover", PhaseId::Review, 0, "新发现识别：提取新线索或退出")
        .node_with("consolidate", PhaseId::Consolidate, 0, "收尾落档")
        .edge("intent", "retrieve", Some("done"))
        .edge("retrieve", "prepare", Some("done"))
        .edge("prepare", "deliberate", Some("done"))
        .edge("deliberate", "consolidate", Some("done"))
        .edge("deliberate", "compact", Some("overflow"))
        .edge("compact", "prepare", Some("done"))
        .edge("deliberate", "discover", Some("max_rounds"))
        .edge("discover", "retrieve", Some("new_findings"))
        .edge("discover", "force_compact", Some("no_new_findings"))
        .edge("force_compact", "consolidate", Some("done"))
        .edge("deliberate", "consolidate", Some("cancelled"))
        .build()?;
    for node in bp.nodes.iter_mut() {
        node.budget.max_activations = Some(match node.id.as_str() {
            "prepare" | "deliberate" => MAX_LOOP_ROUNDS,
            "compact" => MAX_LOOP_ROUNDS.saturating_sub(1),
            "retrieve" => 3,
            "discover" => 2,
            _ => 1,
        });
    }
    Ok(bp)
}
```

intent_node.rs（新文件）：

```rust
//! 意图识别节点：包 analyze_input_intent 的场景化实现
//!
//! 失败降级为空 IntentAnalysis 继续走图（types.rs IntentAnalysis doc 的既有约定：
//! 不阻塞主流程），错误只留日志——意图识别是增强，不是闸门。

use super::context::AwakenDeps;
use crate::pkg::think_path::{ContextKey, LoadDepth, NodeContract, NodeId, NodeOutcome, NodeSignal, PhaseId, ThinkBus, ThinkNode};
use crate::models::events::AgentLoopEvent;
use crate::service::domain::runtime::types::IntentAnalysis;
use async_trait::async_trait;
use common::error::Result;
use std::sync::Arc;

pub(crate) const NODE_INTENT: &str = "intent";

pub struct IntentNode {
    deps: Arc<AwakenDeps>,
}

impl IntentNode {
    pub fn new(deps: Arc<AwakenDeps>) -> Self { Self { deps } }
}

#[async_trait]
impl ThinkNode for IntentNode {
    fn id(&self) -> NodeId { NodeId::new(NODE_INTENT) }
    fn phase(&self) -> PhaseId { PhaseId::Triage }
    fn purpose(&self) -> &str { "意图识别：产出结构化 IntentAnalysis（失败降级空结构）" }
    fn contract(&self) -> NodeContract {
        NodeContract {
            requires: vec![],
            reads: vec![],
            writes: vec![ContextKey::Intent],
        }
    }
    async fn run(&self, bus: &mut ThinkBus) -> Result<NodeOutcome> {
        let deps = &self.deps;
        let trace_id = format!("intent-{}", deps.trace_id);
        let started = std::time::SystemTime::now();
        let _ = crate::pkg::aop::publish(&deps.ctx, AgentLoopEvent::started(&deps.agent.po.id, &trace_id, "intent-analyze", None)).await;

        let analysis: IntentAnalysis = match deps.backend
            .analyze_intent(deps, super::backend::IntentInput { trace_id: trace_id.clone() })
            .await
        {
            Ok(ia) => ia,
            Err(e) => {
                // 降级：空 IntentAnalysis，主流程照常（检索节点对空词自行短路）
                crate::log_error!(&deps.ctx, "legacy_awaken", "intent analyze degraded to empty: agent_id={}, error={}", deps.agent.po.id, e);
                IntentAnalysis::default()
            }
        };
        crate::log_info!(&deps.ctx, "legacy_awaken", "intent node done, agent_id={}, intent_type={}, confidence={}, key_terms={}", deps.agent.po.id, analysis.intent_type, analysis.confidence, analysis.key_terms.len());

        let duration_ms = started.elapsed().map(|d| d.as_millis() as u64).unwrap_or(0);
        let _ = crate::pkg::aop::publish(&deps.ctx, AgentLoopEvent::finished(&deps.agent.po.id, &trace_id, "intent-analyze", "success", duration_ms, None)).await;

        let value = serde_json::to_value(&analysis)
            .map_err(|e| common::error::err!(Internal, "encode intent analysis failed: {e}"))?;
        bus.insert(ContextKey::Intent, LoadDepth::Full, value);
        Ok(NodeOutcome::new(NodeSignal::Done))
    }
}
```

```rust
//! 检索节点（机械）：按意图关键词做知识混合检索 + 思维方法技能召回
//!
//! 不调模型。输入=bus[Intent] + deps.retrieval（visited 差集），
//! 输出=bus[Knowledge] 的 RetrievalPack。空词/零命中都是合法结果（照常 done）。

use super::context::{AwakenDeps, RetrievalPack, RetrievalState};
use crate::pkg::think_path::{ContextKey, LoadDepth, NodeContract, NodeId, NodeOutcome, NodeSignal, PhaseId, ThinkBus, ThinkNode};
use crate::service::dao::memory::MemorySearch;
use crate::service::domain::runtime::RuntimeMemory;
use async_trait::async_trait;
use common::error::Result;
use std::sync::Arc;

pub(crate) const NODE_RETRIEVE: &str = "retrieve";

/// 知识命中条数上限（机械 Top-K）
const KNOWLEDGE_TOP_K: i32 = 5;
/// 方法技能条数上限
const METHOD_SKILLS_TOP_K: usize = 2;
/// thinking_method 技能的 tag 约定值（与 seed 技能、settle 登记共用同一真相）
pub(crate) const METHOD_SKILL_TAG: &str = "thinking_method";
```

节点实现要点（完整实现按此写）：
- `contract`：`reads: vec![ContextKey::Intent], writes: vec![ContextKey::Knowledge]`；phase `Prepare`。
- `run()`：
  1. `read_bus::<IntentAnalysis>(bus, ContextKey::Intent)`（`super::context::read_bus`），失败按默认空结构继续；
  2. 锁 `deps.retrieval` 取快照（防 MutexGuard 跨 await，照 BusinessProvider L306-L310 模式）；
  3. 候选词 = `ia.key_terms` 去重后与 `state.queried_terms` 求差集；**差集为空 → 写空 pack（保留旧 pack 的 prior_thinking_summary，若 bus 已有 Knowledge 分区）→ Done**（无新息不查库）；
  4. 知识检索：`deps.domain.search(deps.ctx.clone(), MemorySearch { keyword: Some(new_terms.join(" ")), top_k: Some(KNOWLEDGE_TOP_K), ..Default::default() }).await`，失败降级为空命中（log_error，不阻断——检索是增强）；
  5. 命中格式化：每条 `format!("- {}", m.content)` 截前 160 chars（`Memory.content` 字段，见 src/models/memory.rs；若字段名不同以实际为准）；
  6. 方法技能：`crate::service::dal::skill::dal().list_published_by_tag(ctx, METHOD_SKILL_TAG)`（dal 全局访问器见 src/service/dal/skill.rs#L24；trait 方法签名见 hr/skill.rs#L190），机械排序：与 new_terms 有词面重叠（description 小写包含任一 term 小写）者优先，取前 `METHOD_SKILLS_TOP_K` 个的 `.po`；
  7. 写 `RetrievalPack { query_terms: new_terms.clone(), knowledge_hits, method_skills, prior_thinking_summary: 旧值透传 }` 到 `bus[Knowledge]`；更新 `deps.retrieval`：`queried_terms.extend(new_terms)`；
  8. `log_info!`（词数/命中数/技能数），返回 `Done`。

discover_node.rs 内实现：

```rust
/// discover 软预算：最多 2 轮「再检索」（蓝图 ActivationBudget=2 是硬护栏）
const MAX_DISCOVERY_ROUNDS: usize = 2;

fn build_discover_prompt(user_message: &str, trail_lines: &[String], queried_terms: &[String]) -> String {
    // 短聚焦：只给三样东西——用户诉求、本轮思考轨迹摘要、已检索词。
    // 刻意不走 PromptBuilder：本节点的价值就是短，全量上下文反而稀释重点。
    format!(
        "用户诉求：{user_message}\n\n本轮思考轨迹（按序）：\n{}\n\n已检索过的关键词：{}\n\n\
         任务：审视上述思考轨迹，判断是否出现了**值得检索但尚未检索**的新线索。\n\
         输出 JSON（不要输出其他内容）：\n\
         {{\"new_key_terms\": [\"...\"], \"prior_thinking_summary\": \"一句话概括本轮已尝试与已知的结论\"}}\n\
         规则：new_key_terms 只放未出现在已检索词里的新词；确实没有新线索就给空数组。",
        trail_lines.join("\n"),
        queried_terms.join("、")
    )
}

/// 解析 discover 输出（复用 intent 解析同套路：直接解析 → 括号提取 → 宽容字段）
pub(crate) fn parse_discovery_json(text: &str) -> DiscoveryOutcome { ... }
```

`parse_discovery_json` 实现套路照 intent_analyze.rs 的 `try_lenient_parse`（L289-L344）：`serde_json::from_str` 直接试 → `extract_first_json_object`（intent_analyze.rs#L350，经 awakening.rs#L35 re-export）提取再试 → 逐字段宽容提取（数组字段混入非字符串照抄过滤逻辑）→ 全失败返回 `DiscoveryOutcome::default()`（**不报错**：解析失败 = 无新息，走退出路径，模型输出抖动不该炸主流程）。
