## 一、目标

1. **词表可信**：实体类 / 关系类型 / 同义映射 3 张全局表落 SQLite（STRICT + status 软删除 + INTEGER 秒级时间戳，无 organization_id）；运行时词表以 DB 为准，`KnowledgeRelationType` 枚举降级为 seed 初始来源 + 展示回落。
2. **惰性解析**：漂移判定是"以当前词表为参数的纯函数"——common/src/ontology.rs 提供 OntologyLexicon + resolve，本体修订后历史漂移自动愈合，零数据迁移；数据库不出现任何物化漂移列。
3. **写只观察、读只解释**：runtime 记忆写方法尾部唯一动作 `aop::publish(MemoryTermsWritten)`（不打点不解析，决策 #16）；认证（published 置位 / needs_review）、漂移统计打点与看板聚合全在消费侧 / 读路径；MemoryDal 零改动零感知。
4. **published 软门禁**：写后认证 certify——resolve 命中置位，Drift 标 needs_review 不拦截不撤回；存量图谱 grandfather 不回填。
5. **注入跟 seed 走**：初始化组织（POST /organization/initialize run_steps）一次性注入 + 管理页同步按钮仅补缺（OnlyMissing，同步返回不走后台任务）；**不做启动自动注入**（决策 #15）。
6. **前端双 tab 一体**：/hr/knowledge-graph 改父壳——「知识图谱」现状平移零重写 +「本体管理」（词表 CRUD / 同义映射 / 漂移看板 / 同步按钮），路由与导航零迁移。

## 二、架构思路

**分层要点（对齐 design §二 / §三）：**

- **common 层**：ontology.rs 纯函数（OntologyLexicon 查找结构 + ResolvedTerm 三分支 + resolve 入口，无 IO 无时钟）；api/ontology.rs CRUD / 看板 DTO 单一事实源，双端共用。
- **DAO 层**：dao/ontology/ 三表 CRUD + `list_all` 全量词表；dao/memory/sqlite.rs 追加词频 GROUP BY 聚合（漂移统计 SQL 的家）。
- **DAL 层**：OntologyDal 组合 OntologyDao + MemoryDao（观察者侧组合，对齐 traverse_knowledge_graph 先例）——词表加载、看板聚合（GROUP BY 词频 + 内存 resolve）；MemoryDal 零改动。
- **Domain 层**：hr/ontology.rs OntologyDomain——词表 CRUD 编排、写后校验（domain/range/required_fields）、`apply_default_lexicon` 幂等注入（只新增）、`certify_memory_terms` 写后认证、看板查询编排；hr/mod.rs 仅声明挂载，**不建 init_base_data**。
- **写路径侵入点（唯一）**：domain/runtime/memory.rs `impl RuntimeMemory for RuntimeDomainImpl` 的 create / update 写方法尾部——原文落库后唯一动作 `aop::publish(MemoryTermsWritten)`（对齐 awakening.rs 同模块先例）；追加式不改签名，**只依赖 pkg/aop，零 domain/dal/stats 新依赖**——认证与统计全在消费者：OntologyCertifyConsumer 异步调 OntologyDomain.certify_memory_terms（消费者→Domain 合法方向，禁 runtime→hr 同层互调）+ record_event! 记 OntologyDriftEvent（消费侧 ctx storage 全局兜底，request_context.rs#L603 先例），业务与统计彻底解耦（单管道，决策 #16）。
- **DuckDB 事件**：StatsEvent derive 宏一步定义（对齐 task_event.rs 形态），collector.rs 注册一行；打点发生在 OntologyCertifyConsumer 内（对齐 tool_exec_stats_consumer.rs "替代直打点 Decorator" 迁移先例）——写路径不发统计，统计归消费侧，单事件管道。
- **seed 管道**：SeedSnapshot 扩 ontology 段 + default.json 内置词表（15 规范关系词 + 4 节点类，display_name 复用 zh_label_from_display 中文名）；initialize_system run_steps 注入 + sync_preset_ontology preview/sync（数据源 embedded_default_snapshot，方法调 hr 域注入，页面归 hr 路由挂 /system）。
- **前端**：knowledge_graph.rs 加页面级 tab 枚举（对齐 agent_memory_panel.rs 的 MemoryTab 模式）；ontology_panel.rs 新面板（CRUD 表格 + 同义映射 + 看板卡 + 同步 Modal）。

技术栈：Rust (Axum + sqlx 0.8 + SQLite STRICT + DuckDB) · Dioxus 0.7 (WASM) · Tailwind v4 + DaisyUI v5。
