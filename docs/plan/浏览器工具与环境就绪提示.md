## 一、目标

| 问题 | 解决方式 |
|------|---------|
| `http_fetch` 抓不到 JS 渲染页 | 新增 Builtin 内置工具 `browser`，包装 agent-browser CLI（Manual，tag: `browser`） |
| 页面交互（点击/填表）无能力 | 透传原子子命令（open/snapshot/click/fill 等），daemon 常驻页面状态跨调用保持 |
| 绑定了工具但宿主机未装 CLI，绑定时无感知 | **tool_readiness 统一体系**：工具清单 `runtime_ready` 预检 + 前端绑定页警示 badge + 调用时结构化引导兜底 |
| lark_cli/gh_cli 缺失时报错泛化 | spawn 报错统一走 tool_readiness 引导（存量工具一并修复） |
| tavily_search 的 key 探测内联在工具内 | 迁入 tool_readiness，清单级可见 |

**收敛后效果**：Agent 具备「打开渲染页 → 快照定位 → 交互 → 截图取证」闭环；「选择了工具但环境缺失」在选工具、绑定、执行三个接触点都有清晰提示。

## 二、架构思路

```
browser.call(ctx, params)
    → tool_readiness::ensure_binary("agent-browser", config [browser].command)
        未找到 → { error_code: "cli_not_installed",
                   install: "brew install agent-browser 或 cargo install agent-browser",
                   hint: "或在 ai_orz.toml [browser].command 配绝对路径" }
    → 子命令白名单校验（open/read/snapshot/click/fill/type/press/scroll/
                       screenshot/wait/close/...）
    → tokio::Command spawn（不经 shell，argv 直拼）
        固定参数: --session ai-orz-agent-{agent_id}（会话隔离）
    → 超时 + stdout/stderr 合并 + 截断
    → screenshot 子命令: 输出落 ArtifactManage 产物存储，返回引用

就绪预检（读路径，带用户上下文）：
list/query/search tools handler → to_list_item
    → tool_readiness::probe(tool_id, ctx.uid)（TTL 缓存，只读）
        CLI 型: 二进制可寻址（config 绝对路径优先 → PATH）
        key 型: 共享 config key 非空 OR 该用户凭证库含对应 kind（如 TavilyKey）
    → ToolListItem.runtime_ready: ready | not_ready{reason,hint} | unknown
前端 agent_detail「工具与技能」页 → 未就绪 badge
```

**关键边界**：Manual 人工确认；白名单防脚本执行类子命令；headless 固定；截图落存储不内嵌 base64；探测只读 + TTL 缓存 + 异常返回 unknown。

## 四、分发点速查表

| 改动点 | 入口 | 要点 |
|--------|------|------|
| CLI 探测 | tool_readiness.rs | 优先 config 绝对路径 → PATH 扫描；引导错误含 install 命令与配置指引 |
| 授权可达探测 | tool_readiness.rs | key 型工具带用户上下文：共享 config key 非空 OR 用户凭证库含对应 kind（经 Resolver 接口查询，不解密） |
| TTL 缓存 | tool_readiness.rs | CLI 型按 tool_id、key 型按 (tool_id, user_id) 缓存，过期重探；探测异常返回 unknown 不阻塞列表 |
| 子命令白名单 | browser.rs 常量数组 | 原子操作集；eval/脚本类一律拒绝并说明原因 |
| 会话隔离 | browser.rs spawn 参数 | `--session ai-orz-agent-{agent_id}`，从 ctx 取 agent_id |
| 截图链路 | browser.rs screenshot 分支 | 临时文件 → ArtifactManage 存储 → 返回 { artifact_id, path } |
| 报错统一 | lark_cli.rs / gh_cli.rs / tavily_search.rs | spawn Err 的 NotFound 分支与 key 检查替换为 tool_readiness 引导 |
| DTO 扩展 | common/src/api/tool.rs | `runtime_ready` 枚举字段，serde 序列化对前端友好 |
| handler 组装 | response.rs to_list_item | 探测结果写入字段；list/query/search 共用一处组装 |
| 前端 badge（清单页） | tools.rs | 新增「就绪」列，三态 badge + title 提示 reason/hint；筛选工具时即可见 |
| 前端 badge（绑定页） | agent_detail.rs | runtime_ready == not_ready 时 badge-warning + hint 提示文案 |
| 注册 | builtin.rs | 工厂入表 + tags == ["browser","network"] 断言 |
