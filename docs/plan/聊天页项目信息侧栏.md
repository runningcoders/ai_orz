# 聊天页信息侧栏（ChatSidePanel）

## 背景

沟通页面（`frontend/src/pages/message/chat.rs`）目前只展示项目名称与消息流，缺失项目总览、进行中任务、执行计划/结果、产物等上下文；默认对话（无项目）模式则完全没有侧栏信息。后端 API 已全部就绪（`GET /projects/{id}` 支持 `with_progress_summary` / `with_task_graph` / `with_artifacts`），本次为纯前端改造 + 一处 API 客户端补参。

## 交互设计

- 默认收起；Header 右侧出现「信息面板」切换按钮（项目对话与默认对话均显示），点击展开/收起
- 展开状态持久化到 localStorage（key: `chat_project_panel_open`），刷新页面后恢复
- 桌面端（lg 及以上）：右侧静态列 `w-96`；移动端：固定右侧抽屉覆盖层（复用左侧栏抽屉模式，带关闭按钮）
- 面板头部：刷新按钮（手动）+ SSE 收到当前会话新消息时自动防抖刷新（2s，后到覆盖先到）

## Tab 结构（按对话模式动态组装）

| 模式 | Tab 序列 |
|------|---------|
| 项目对话（选中 project） | 总览 / 任务 / 产物 / Agent |
| 默认对话（无 project） | Agent（前台） / 我 |

Agent Tab 为两种模式共用的独立组件，实现"两种对话情况复用"。

## 新增组件 `frontend/src/components/chat/chat_side_panel.rs`

主组件：`ChatSidePanel { project_id: Option<String>, reception_agent_id: Option<String>, refresh_tick: u64, on_close: Option<Callback> }`（on_close 仅移动端抽屉用）。在 `components/chat/mod.rs` 注册导出。文件内部包含各 Tab 子组件（私有函数/子 component）。

### 数据加载

- `use_effect` 监听 `project_id` 与 `refresh_tick`：
  - 项目模式：并行 `get_project(id, with_progress_summary=true, with_task_graph=true, with_artifacts=true)` + `list_project_tasks(id)`
  - 默认模式：无需预加载（Agent/用户 Tab 各自懒加载）
- `refresh_tick` 变化时 `spawn` 防抖：sleep 2s 后重新加载（代际计数丢弃过期请求）
- Tab 结构：`active_tab: usize`，DaisyUI `tabs tabs-boxed` 小号样式；模式切换时重置为 0

### Tab 总览（仅项目模式）

- 状态徽标（`project_status_badge/text`）+ tags + 优先级 + 负责人 Agent ID
- 项目描述（项目目标），`MarkdownRenderer compact`
- 进度汇总：`progress_summary.overall_percent` 进度条（`progress_bar_class`）+ 各状态计数（完成/进行中/待启动/已取消）
- 执行计划 / 执行结果：非空时 `MarkdownRenderer compact` 展示（与详情页「规划与执行」一致，只读）
- 任务依赖图：`task_graph` 非空时 `MermaidDiagram`

### Tab 任务（仅项目模式）

- 任务列表项：标题 + 状态徽标 + 进度条 + 负责人
- 点击切换单任务展开（`expanded_task_id: Option<String>`，参照 memory_search 模式）
- 首次展开时懒加载 `get_task(id, with_artifacts=true)`，缓存到 `HashMap<String, GetTaskResponse>` 信号；再次展开直接命中缓存
- 展开内容：描述（Markdown compact）、开始/截止时间、进度百分比、执行计划/执行结果（Markdown compact）、产物名称列表、`Link` 跳转 `Route::TaskDetail`

### Tab 产物（仅项目模式）

- 数据源为 `get_project` 的 `artifacts`（with_artifacts）
- 纯函数 `split_artifacts(&[ArtifactDetail]) -> (Vec<&ArtifactDetail>, Vec<&ArtifactDetail>)`：`task_id` 为 None 归项目级，Some 归任务级
- 项目级区块：直接列表；任务级区块：按 `task_id` 分组，组标题取 tasks 列表中的任务名（查不到显示任务 ID 截断）
- 每行：名称、来源类型徽标（新文件内私有版 `artifact_source_type_text`）、文件大小（`format_file_size`）、创建时间、`Link` 跳转 `Route::ProjectArtifactDetail`；只读，不含新增/删除

### Tab Agent（两种模式共用）

- 组件 `AgentInfoTab { agent_id: String }`，内部 `get_agent` 懒加载 + 缓存
- 项目模式传入 `project.owner_agent_id`（None 时空状态提示"项目未指定负责人"）；默认模式传入 `reception_agent.agent_id`
- 展示：名称、类型徽标（kind: local/cli/remote）、生命周期状态徽标、运行时状态（空闲/忙碌）、roles 徽标组、capabilities 列表、描述（Markdown compact）、绑定工具数量、`Link` 跳转 `Route::AgentDetail`
- 不展示 soul 提示词（敏感内部配置）

### Tab 我（仅默认模式）

- `get_current_user_info()` 懒加载（`frontend/src/api/organization.rs` 已有）
- 展示：显示名/用户名、邮箱、角色徽标（role_name）、状态；账号信息只读
- 底部 `Link` 跳转 settings 页面（主题等偏好编辑仍在 settings，不在侧栏内嵌编辑）

## `frontend/src/api/project.rs` 修复

`get_project` 的 `build_query_string` 补传 `with_progress_summary`（DTO 已有字段，仅查询串遗漏）。

## `chat.rs` 改动

- 新增信号：`panel_open`（从 localStorage 初始化，切换时回写）、`refresh_tick: u64`
- `handle_sse_message` 中会话匹配命中时 `refresh_tick += 1`
- 两种对话 Header 右侧均追加「信息面板」切换按钮
- 布局：chat 主列后条件渲染 `ChatSidePanel`；桌面 `hidden lg:flex w-96 flex-col border-l`；移动端 `fixed inset-y-0 right-0 z-50 w-80` 抽屉 + 背景遮罩点击关闭
- 项目/默认模式切换时仅切换 Tab 数据集，panel_open 状态保持

## 假设与边界

- 面板纯只读：不含任务/产物创建、状态变更、用户资料编辑（这些仍在各自详情页/设置页完成）
- 任务负责人仅显示 Agent ID 文本，不额外批量查 Agent 名称（避免 N+1，后续可增强）
- Mermaid 图在窄面板中可能溢出，沿用 `MermaidDiagram` 自带的 `overflow-x-auto`
- 手动验证：浏览器中分别打开默认对话与项目对话，确认各 Tab 数据、任务展开、产物分组、Agent/用户 Tab、移动端抽屉与双刷新机制
