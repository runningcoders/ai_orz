模块以 Playwright 为核心编排层：`playwright.config.ts` 定义两个 project——`setup`（匹配 `*.setup.ts`）负责首次系统初始化与登录并持久化 `.auth/state.json`，`chromium` project 依赖 setup 并通过 `storageState` 复用登录态；`webServer` 通过 `scripts/start-server.mjs` 拉起独立端口（默认 3310）的后端进程，使用隔离数据目录 `.e2e-runtime/ai_orz.toml` 避免与本地开发服务冲突。测试用例按职责拆分：`tests/auth.setup.ts` 走完整「初始化→错误密码→登录成功」流程并保存 storageState；`tests/navigation.spec.ts` 用参数化用例逐个访问主要路由，断言 Navbar、关键文案 marker 及无 `.alert-error`，并在失败时归档 pageerror/console 日志。诊断脚本 `scripts/diagnose-page.mjs` 提供白屏排查能力。整体依赖方向单向：test → playwright config → start-server → 后端二进制，不反向依赖业务代码。
