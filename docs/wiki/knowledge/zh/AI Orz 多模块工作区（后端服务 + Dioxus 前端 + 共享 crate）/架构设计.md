仓库采用 Cargo workspace 将后端二进制（src/main.rs）、Dioxus 前端（frontend/）、共享 DTO/枚举库（common/）、宏 crate（ai-orz-macros/）与 Playwright E2E（e2e/）并列管理；后端按四层架构拆分：src/handlers 暴露 HTTP/A2A 适配层，src/service/domain 承载领域编排，src/service/dal 负责 PO↔Entity 转换，src/service/dao 封装本地 DB CRUD 与外部 API 出站，src/pkg 提供无业务感知的 AOP、存储、工具注册等基础设施，src/models 集中定义 PO、实体与内部事件；handlers 与 producer/consumer 通过 pkg/aop 的事件队列解耦，DAO 之间禁止互相调用、DAL 不调 DAL、Domain 不调 Domain，所有跨层依赖由 service/mod.rs 组装；数据库版本由 migrations/*.sql 经 sqlx 管理，前端通过 common crate 与后端共享 API DTO、枚举与错误类型，确保前后端契约一致。
