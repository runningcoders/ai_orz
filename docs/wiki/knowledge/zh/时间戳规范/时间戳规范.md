## 1. 概述

本卡片定义 AI Orz 全项目时间戳的统一规范——单位、生成方式、存储格式与展示约定。核心决策为：**全部使用毫秒级 Unix 时间戳（i64）**，UTC 时区存储，`common::constants::utils::current_timestamp_ms()` 为唯一生成入口。DAO 层允许 `chrono::Utc::now().timestamp_millis()` 作为例外以减少依赖。

## 3. 架构约定

### 3.1 字段命名

| 字段名 | 含义 | 单位 |
|---|---|---|
| `created_at` | 创建时间（首次写入，不可变） | 毫秒 i64 |
| `updated_at` | 更新时间（每次修改自动更新） | 毫秒 i64 |
| `deleted_at` | 软删除时间（0 或 NULL 表示未删除） | 毫秒 i64 |
| `start_at` / `end_at` | 业务开始/结束时间 | 毫秒 i64 |
| `due_at` | 截止时间 | 毫秒 i64 |
| `expire_at` | 过期时间 | 毫秒 i64 |
| `last_followup_at` | 最近跟进时间 | 毫秒 i64 |

### 3.2 时区

- **存储统一 UTC**：所有时间戳以 UTC 时区存储，展示时按用户时区转换。
- **数据库 INTEGER**：SQLite 使用 `INTEGER NOT NULL` 存储 i64 毫秒值，精度覆盖至 2262 年。

### 3.3 工具函数

```rust
// Model / Domain / Handler 层唯一入口
use common::constants::utils;
let now_ms = utils::current_timestamp_ms();

// DAO 层允许的例外（减少 import 依赖）
let now = chrono::Utc::now().timestamp_millis();
```

### 3.4 数据库 DEFAULT

```sql
-- 毫秒级默认值（用于 tools/agent_tools/vector_metadata 等表）
DEFAULT (CAST(strftime('%s', 'now') * 1000 AS INTEGER))
```

## 4. 硬约束

1. **禁止本地 `current_timestamp()` 实现**：不得在任何模块自定义时间戳函数，统一使用 `common::constants::utils::current_timestamp_ms()`。
2. **禁止 `timestamp()` 秒级**：不得使用 `chrono::Utc::now().timestamp()` 或 `SystemTime::now().duration_since(UNIX_EPOCH).as_secs()`，一律使用 `timestamp_millis()` / `as_millis()`。
3. **禁止 DAO 层外的 `Utc::now().timestamp_millis()`**：仅 DAO 层 SQL 写入前的本地变量场景允许，其余层级必须走公共工具。
4. **PO 字段注释必须标注「毫秒级」**：每个时间字段的文档注释需明确标注「毫秒级 Unix 时间戳」。
5. **DEFAULT 必须乘 1000**：SQLite DEFAULT 表达式 `strftime('%s', 'now')` 为秒级，必须乘以 1000 转为毫秒。
6. **时间运算必须单位一致**：`interval_seconds * 1000` 转毫秒后再运算，禁止秒级变量与毫秒变量混用。
7. **Cron 调度统一毫秒**：`cron_triggers.next_run_at` / `last_run_at` 为毫秒级，`src/pkg/cron.rs` 中 `timestamp_millis()` 为唯一入口。
8. **前端格式化默认毫秒**：`new Date(timestamp)` 直接接收毫秒值，兼容秒级旧数据使用 `ts < 1e12 ? ts * 1000 : ts` 兜底。
9. **迁移脚本需乘以 1000**：数据迁移时旧数据秒级转毫秒需 `* 1000`，同步修改 `20260420000000_initial.sql` 中的 DEFAULT。
10. **禁止 `SystemTime::now()` 裸用**：不得直接使用 `SystemTime::now().duration_since(UNIX_EPOCH)` 获取时间，必须封装进 `current_timestamp_ms()` 或 DAO 层 chrono 调用。
