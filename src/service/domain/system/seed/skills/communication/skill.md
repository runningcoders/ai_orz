# 协作沟通

本指南帮助你与用户、其他 Agent 高效沟通协作。沟通是协作的基础，像团队成员一样，你需要主动沟通、及时反馈、闭环负责。

## 沟通对象

| 对象 | 工具 | 场景 |
|------|------|------|
| **用户** | `send_message` | 汇报进展、请求确认、通知事件 |
| **其他 Agent** | `send_message_to_agent` | 直接通信、协调工作 |
| **任务分配** | `send_task_assignment_message` | 委派任务给其他 Agent |

## 与用户沟通

### `send_message` — 发送消息
向用户发送消息，是你在对话中的主要沟通方式。

**使用时机**：
- 汇报工作进展和阶段成果
- 遇到模糊需求时请求 clarification
- 需要用户确认或决策时
- 通知重要事件或状态变更
- 任务完成时总结反馈

**沟通原则**：
- **主动沟通**：遇到不确定时主动询问，不要自行假设
- **及时反馈**：进展、阻塞、完成都及时通知
- **清晰简洁**：说重点，避免冗长解释
- **闭环负责**：接受的任务完成后回复结果

### `list_messages` — 查看历史消息
查看历史消息，了解上下文。

**使用场景**：
- 了解之前的讨论和决策
- 追踪任务流转过程
- 避免重复沟通已确认的事项
- 新加入项目时了解背景

### `search_messages` — 搜索消息
按关键词搜索历史消息，适合在大量历史中定位特定信息。

## 与其他 Agent 协作

### `send_message_to_agent` — 向其他 Agent 发消息
直接向指定 Agent 发送消息，用于点对点沟通。

**使用场景**：
- 协调并行工作的依赖关系
- 请求其他 Agent 协助
- 同步重要信息给相关方
- 回复收到的任务或消息

### `send_task_assignment_message` — 分配任务
向其他 Agent 委派任务，包含清晰的任务描述。

**委派原则**：
- **明确边界**：清晰描述任务目标、输入和预期输出
- **能力匹配**：根据目标 Agent 的角色和技能选择合适对象
- **避免重复**：委派前确认任务尚未被其他人处理
- **追踪状态**：委派后关注进展，及时跟进

**委派流程**：
1. 用 `query_agents` 或 `search_agents` 查找合适的协作 Agent
2. 用 `send_task_assignment_message` 发送任务，包含清晰需求
3. 目标 Agent 接收后处理，结果通过消息返回
4. 收到结果后确认并整合到当前工作

## 发现协作伙伴

### `query_agents` — 查询 Agent 列表
按条件查询组织内的 Agent，了解可用的协作伙伴。

### `search_agents` — 搜索 Agent
按能力、角色等关键词搜索合适的 Agent。

### `get_agent` — 获取 Agent 详情
查看指定 Agent 的详细信息，包含角色、能力、已安装技能等。

### `get_reception_agent` — 获取前台接待 Agent
获取组织的前台接待 Agent，用于转接用户请求或未知类型的任务。

## 协作场景

### 场景一：分工合作
多个 Agent 共同完成一个项目：
1. 明确各自负责的模块（通过 `send_message` 确认分工）
2. 用 `send_task_assignment_message` 委派子任务
3. 各自完成后保存成果（参考"项目管理"技能）
4. 用 `send_message` 同步进展和依赖

### 场景二：能力互补
遇到不擅长的领域：
1. 用 `search_agents` 查找有相关能力的 Agent
2. 用 `send_message_to_agent` 沟通需求
3. 委派任务并说明上下文
4. 收到结果后整合

### 场景三：知识传递
完成任务后沉淀知识供团队复用：
1. 用 `save_short_term_memory` 记录经验（参考"记忆认知"技能）
2. 重要方案用产物保存（参考"项目管理"技能）
3. 用 `send_message` 通知团队成员

## 行为准则

1. **主动沟通**：遇到模糊需求时主动询问，不要自行假设
2. **及时反馈**：任务进展、阻塞、完成都应及时通知相关方
3. **成果留痕**：重要工作保存为产物，不要只存在对话中
4. **尊重边界**：不越权操作其他 Agent 的资源，通过委派和消息协作
5. **闭环负责**：委派出去的任务要跟进结果，接受的任务要按时完成并回复
6. **清晰表达**：沟通时说重点，结构化表达，避免歧义
