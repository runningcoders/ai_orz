# 技能基础

本指南帮助你理解技能系统，掌握技能查询、搜索、安装、卸载的成长性能力管理。技能是你扩展自身能力的核心机制。

## 技能是什么

技能是可复用的工作能力封装，包含工作方法、领域知识、操作规范。与工具的区别：
- **工具**：具体的执行接口，有输入输出参数
- **技能**：方法论和知识，指导你如何使用工具和完成任务

## 技能加载机制

技能按标签（tags）控制加载范围：

| 类型 | 标签 | 加载方式 |
|------|------|---------|
| **常驻技能** | tags 含 `neural` | 所有 Agent 必加载，直接出现在 Prompt 中 |
| **按需技能** | tags 不含 `neural` | 匹配 Agent 角色或已安装工具包才会加载 |
| **隐藏技能** | 未匹配且未搜索 | 通过 `search_skill` 按需发现加载 |

你当前看到的本指南就是常驻技能之一。

## 技能查询与搜索

### `search_skill` — 搜索技能
按关键词或标签搜索技能库，返回匹配的技能列表。遇到不熟悉的领域时，优先用此工具发现可用技能。

**适用场景**：
- 接到新任务，检查是否有相关技能
- 遇到不熟悉的概念，搜索是否有指南
- 想提升某方面能力，查找可安装的技能

### `search_skills` — 批量搜索
支持多个关键词批量搜索，适合一次了解多个相关技能。

### `list_skills` — 列出技能
返回技能列表，支持分页和过滤。适合浏览全部可用技能。

### `query_skills` — 按条件查询
按 tags、状态、作者等条件精确查询。适合按分类筛选。

### `list_skill_tags` — 列出技能标签
返回所有已发布技能的标签聚合。用于发现技能包分类，了解平台技能全貌。

### `get_skill` — 获取技能详情
查看指定技能的完整信息，包含内容路径和文件列表。

### `list_skill_files` / `get_skill_file_content` — 读取技能文件
查看技能的具体内容文件。常驻技能已加载到 Prompt，按需技能需要主动读取。

## 技能安装与卸载

### `install_skill_to_agent` — 安装技能
将技能安装到自己的技能目录，创建副本。安装后：
- 技能副本出现在你的工作目录 `agents/{你的ID}/skills/` 下
- 即使原技能更新，你的副本不受影响（独立版本）

### `install_skill_pack` — 安装技能包
按标签批量安装一组技能。适合一次获取某个领域的完整能力包。

### `uninstall_skill_from_agent` — 卸载技能
卸载不再需要的技能副本，释放 Prompt 空间。仅能卸载自己安装的副本，不能卸载常驻技能。

### `uninstall_skill_pack` — 卸载技能包
按标签批量卸载一组技能。

## 成长性能力管理

像人一样，你的能力可以通过持续学习成长：

### 能力扩展
1. 遇到新领域任务 → `search_skill` 搜索是否有相关技能
2. 发现有用技能 → `install_skill_to_agent` 安装到自己的技能库
3. 需要完整能力包 → `install_skill_pack` 按标签批量安装

### 能力维护
1. 定期检查已安装技能 → `list_skills` 查看当前技能集
2. 清理过时技能 → `uninstall_skill_from_agent` 卸载不再需要的
3. 更新技能认知 → `list_skill_tags` 浏览最新技能分类

### 知识沉淀
完成重要任务后，将经验沉淀为记忆（参考"记忆认知"技能），这些经验会指导你未来更好地使用技能。

## 最佳实践

1. **先搜后装**：安装前先 `search_skill` 了解技能内容和适用性
2. **按需安装**：只安装当前任务需要的技能，避免 Prompt 过载
3. **及时清理**：完成的任务相关技能及时卸载，保持技能库精简
4. **关注标签**：用 `list_skill_tags` 发现新技能包，持续扩展能力认知
5. **学以致用**：安装的技能要实际使用，通过实践巩固能力
